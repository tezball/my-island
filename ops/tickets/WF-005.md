# WF-005 — Dev Container, compose, and CI so any agent can start and test

## Outcome

One `compose.yml` is the runtime for git-clone, Dev Containers, Cursor Cloud Agents, and GitHub Actions. `./scripts/dev up` starts the stack. `./scripts/dev test` runs the same tests CI runs.

## Notes

No consumer MVP. The runnable “app” today is the local ops stack (Postgres + Grafana/Loki/Prometheus/Alertmanager). The workspace image carries the Java/Python/Node toolchain for later `PRD-*` work.
