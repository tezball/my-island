# PRD-007 — Research→leads pipeline acceptance

## Outcome

Acceptance criteria for **Research depositing leads** into [`data/leads/places.jsonl`](../../data/leads/places.jsonl). Leads are **not** published places. Deposits must satisfy the **landed** schema in [`data/leads/schema.json`](../../data/leads/schema.json) (PR #14 / [[tickets/PRD-006]]). This ticket does **not** add, rename, or fork fields.

## Wave 1 scope

Terry (via CEO, 2026-09-06) green-lit the first Research wave. Product bar: [`product/WAVE-1.md`](../../product/WAVE-1.md). Plan: [[plans/PRD-007]].

Wave 1 = Research deposits/updates leads in `places.jsonl` per landed `schema.json`. Create/update here is **JSONL append or update by `dedupe_key`**. Curator promote / Eng draft Place create is [[tickets/PRD-008]]. **Publish is still blocked on [[tickets/PRD-009]]** — Wave 1 does not waive counsel.

## Notes

CEO seed path (Orchestrator, 2026-09-05): aggressive multi-source collection into `data/leads/` with provenance. **Canon is the merged store** — README + `schema.json` + `LEGAL.md`. Do not invent a parallel schema in a plan.

Owner: **product** (acceptance). Research executes as **content-seo**. Relates to [[tickets/PRD-002]]. Promote is [[tickets/PRD-008]]. Counsel is [[tickets/PRD-009]].

Bind to the landed contract (do not restate a second one):

- Required keys: `schema.json` `required` — `id`, `name`, `place_type`, `country`, `source_url`, `source_name`, `fetched_at`, `licence`, `status`, `dedupe_key`
- `additionalProperties: false` — extra keys fail CI (`ops/tests/test_leads.py`)
- Optional facts (`county`, `address`, `eircode`, `lat`, `lng`, `website`, `phone_public`, `email_public`, `notes_original`, `raw_refs`): omit when unknown; never `"-"`
- `status` on deposit is `lead` (enum: `lead` \| `reviewed` \| `rejected` \| `promoted`). Research does not set `promoted`
- Idempotency: README rule 6 — same `dedupe_key` (`place_type:county-slug:name-slug`) or same website host + similar name → update the line
- No PII scrape into git: `email_public` is public business mail only (schema description)
- County / `place_type` are hints from the schema enums; omit county rather than invent; `place_type` is `campsite` \| `bnb` \| `experience` \| `poi` \| `other`
- County hints must fit the same 32-county catalog list (incl. NI); omit rather than invent a name outside that list
