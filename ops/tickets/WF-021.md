# WF-021 — Simple local CLI for start/stop/test

## Outcome

Terry has one local command for the Halfdoor stack: `./scripts/app start`, `./scripts/app stop`, `./scripts/app test`. Start reuses `./scripts/dev up` (PostGIS, Grafana, Loki, Prometheus, Alertmanager, catalog API), opens the human URLs when a display exists, and prints a ready summary. Test brings the stack up if needed, runs the same checks humans care about, and prints a one-screen PASS/FAIL report.

## Notes

CEO ask 2026-09-06. Thin wrapper — do not rewrite compose. Chaos stays **off** on default start (no `compose.chaos.yml`, no Spring profile `chaos`). No consumer UI (that's [[tickets/PRD-003]]). Catalog smoke uses stub fields `categoryId` / `countyId` / `latitude` / `longitude` ([[tickets/WF-018]]).

Id is **WF-021**: WF-016/017/018/020 are on main; WF-019 is claimed by open PR #31.

## Verify

- [ ] `./scripts/app help` prints start / stop / test
- [ ] `./scripts/app start` brings the compose stack up (same as `./scripts/dev up`) and prints Catalog / Grafana / Prometheus / Alertmanager URLs
- [ ] Start opens those URLs with `open` (macOS) or `xdg-open` (Linux) and skips gracefully with no display
- [ ] `./scripts/app stop` runs `./scripts/dev down` and prints a clear stopped message
- [ ] `./scripts/app test` starts the stack if needed, runs `./scripts/dev test` plus catalog `mvnw test` plus health/create/list/get smoke, prints PASS/FAIL per line, exit 0 only when all green
- [ ] Default start does not enable chaos
- [ ] [[workflow/LOCAL]] documents the one-liner
- [ ] `python3 -m pytest ops/tests -q -m "not stack"` green
