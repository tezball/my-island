# Recommended Obsidian plugins

Open **`ops/`** as the vault (not the repo root, not `docs/`). Core settings in `.obsidian/` are committed. **Do not commit plugin binaries** (`main.js`). Install community plugins on your machine.

## Core (enabled in `.obsidian/core-plugins.json`)

| Plugin | Why |
|---|---|
| Templates | New tickets from `templates/` |
| Daily notes | `daily/YYYY-MM-DD.md` from `templates/daily` |
| Properties | Ticket frontmatter (`status`, `priority`, `owner`) |
| Backlinks / outgoing links | Follow `[[wikilinks]]` |
| Graph | See ticket ↔ plan ↔ run |
| Kanban uses a community plugin; `BOARD.md` is still generated by script |

Daily notes: folder `daily`, format `YYYY-MM-DD`, template `templates/daily`.

## Community (listed in `.obsidian/community-plugins.json`)

Install via Settings → Community plugins → Browse. Restricted mode off.

| Plugin id | Name | Use |
|---|---|---|
| `obsidian-kanban` | Kanban | Optional view of [[BOARD]]. **Source of truth is ticket frontmatter + `board_sync.py`.** If the board and a ticket disagree, the ticket wins — regenerate. |
| `dataview` | Dataview | Query tickets and company data (examples in [[data/_index]]) |
| `templater-obsidian` | Templater | Optional; core Templates is enough for agents |
| `obsidian-tasks-plugin` | Tasks | Checklists in runbooks and dailies |
| `calendar` | Calendar | Jump to daily notes |

The historical `docs/` vault used Tasks + Advanced Tables + themes. Do not copy those plugin folders here.

## Dataview snippets

Tickets in flight:

````markdown
```dataview
TABLE status, priority, owner, area
FROM "tickets"
WHERE id AND status != "done" AND type != "epic"
SORT priority ASC, id ASC
```
````

Incidents:

````markdown
```dataview
TABLE status, owner, blocked_reason
FROM "tickets"
WHERE type = "incident"
SORT file.name DESC
```
````

## Agents and Obsidian

Agents edit markdown in git. They do not click the Obsidian UI. Humans use Obsidian to read the vault. After pulling, if Kanban looks stale, run `python3 ops/scripts/board_sync.py`.
