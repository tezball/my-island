# Plan: Repeatable place listing create/list/get sim

## Outcome

Agents can re-run a prod-like happy-path simulation of catalog create/list/get against compose (`http://127.0.0.1:8081` or the catalog service URL) without inventing curl. Done when one script exists, N iterations work, actuators are checked, and CI `unit` stays green without enabling chaos.

## Out of scope

- Chaos Monkey / `compose.chaos.yml` on the default path
- UI/PWA, booking, visits, auth
- Rewriting [`product/STACK.md`](../../product/STACK.md)
- Full [[tickets/PRD-001]] polish
- Overwriting [[tickets/WF-015]], [[tickets/WF-016]], [[tickets/WF-017]], or [[tickets/WF-018]]

## Steps

1. Add `ops/scripts/sim_place_listing.py` at repo-root `ops/` (stdlib urllib/json). Wrapper `scripts/sim-place-listing.sh` is the one command.
2. Happy path: detect catalog (`127.0.0.1:8081` then `http://catalog:8080`), `GET /actuator/health`, then N times unique-slug POST (`categoryId` / `countyId` / `latitude` / `longitude`) → list contains id → GET by id. Optional `GET /actuator/prometheus`.
3. Short pointer on [[workflow/STACK-E2E-place-stub]] / [[workflow/LOCAL]]. Runbook [[runbooks/PLACE_LISTING_SIM]].
4. Fast tests: fake HTTP catalog (no Docker). `@pytest.mark.stack` one live iteration when compose is up.

## Verify

- [x] `./scripts/sim-place-listing.sh` after `./scripts/dev up`
- [x] `--iterations` / `SIM_ITERATIONS`
- [x] Health always; prometheus skippable (`--no-prometheus`)
- [x] No chaos in default sim or CI
- [x] `python3 -m pytest ops/tests -q -m "not stack"`

## MCP / env

Local compose required for the live sim (`./scripts/dev up`). No prod Grafana. Postgres-RO / mcp-grafana is [[tickets/WF-016]], not this ticket.
