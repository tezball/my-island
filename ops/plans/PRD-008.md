# Plan: Eng import / create-update draft Places from data/leads

## Outcome

Engineering can import curator-reviewed leads from [`data/leads/places.jsonl`](../../data/leads/places.jsonl) into the PRD-001 catalog stub as **draft** Places (`published` false). Re-import of the same lead `dedupe_key` updates that draft. Provenance (`source_url`, `source_name`, `licence`) is copied onto the Place. Skip and reject follow the ticket table. **No auto-publish.** [[tickets/PRD-009]] counsel still gates publish. Done when an implementer PR has the thin import path, catalog columns the stub is missing, and the verify steps below pass.

Lead shape is only [`data/leads/schema.json`](../../data/leads/schema.json) (PR #14). Field map is [`product/WAVE-1.md`](../../product/WAVE-1.md). Do not invent lead fields or a parallel DTO.

## Out of scope

- Booking, Stripe, inventory, calendars, partner portals
- Scrapers / collection
- Admin / curator UI (API + script first)
- Consumer PWA ([[tickets/PRD-003]])
- A second lead schema or Java type that restates `schema.json`
- A Spring `country` table or country enum
- Spreadsheet bulk-import / coverage ([[tickets/PRD-002]])
- Publish / unpublish API, `status: promoted` from this importer, waiving [[tickets/PRD-009]]
- Mapping `notes_original` → `description`, or copying `address` / `eircode` / `email_public` / `fetched_at` / `raw_refs` onto Place this ticket

## Pick: script POSTs CreatePlaceRequest-style JSON

Landed stub ([PR #21](https://github.com/tezball/my-island/pull/21)): `POST /api/v1/places` already accepts `name`, `categoryId`, `countyId`, `latitude`, `longitude`, `website`, `phone`, `published`. Host: `http://127.0.0.1:8081`. List/get exist. Same HTTP style as `ops/scripts/sim_place_listing.py`.

Gaps that a script **cannot** close against today’s stub:

1. Place has no `source_url` / `source_name` / `licence` columns (CUR-06).
2. Place has no `lead_dedupe_key` — re-POST 409s on slug (`DuplicateSlugException`).
3. There is no update path.

**Implementer shape (smallest that fits):**

1. **Python CLI** `ops/scripts/import_leads.py` (stdlib + urllib, like the listing sim). Reads JSONL, applies skip/reject rules, maps landed keys → CreatePlaceRequest-style camelCase, `POST`s to `/api/v1/places` with `published: false`. `--dry-run` prints payloads and does not POST. Optional `--reject <lead-id>` sets JSONL `status` to `rejected` and does not POST.
2. **Catalog expand (not a second API house):** Flyway V6 on `place`: `source_url`, `source_name`, `licence`, `lead_dedupe_key` (unique, nullable so workshop/sim rows stay valid). Extend `CreatePlaceRequest` / `PlaceResponse` with `sourceUrl`, `sourceName`, `licence`, `leadDedupeKey` (catalog JSON stays camelCase; **lead** JSON stays snake_case).
3. **POST upsert when `leadDedupeKey` is present:** insert draft, or update the existing **unpublished** row. If that Place is already `published=true`, 409 and do not overwrite. When `leadDedupeKey` is set, **force `published=false`** even if the body says true (importer must not be a publish path). When `leadDedupeKey` is absent, keep today’s create behaviour (E2E-001 / WF-019).

Do **not** add `POST /api/v1/places/from-lead` that parses JSONL inside Spring, and do not add a Lead Java DTO. Mapping lives in the script.

## Field map (landed keys only)

| Lead (`schema.json`) | POST / `CreatePlaceRequest` |
|---|---|
| `name` | `name` |
| `place_type` | `categoryId` — `poi` / `experience` / `campsite` / `bnb` (same ids as [[data/listing-types]] / `V2__category.sql`) |
| `county` | `countyId` — slug on the 32-county table (`V4__county.sql`, incl. NI) |
| `lat` | `latitude` (omit if absent; do not invent) |
| `lng` | `longitude` (omit if absent; do not invent) |
| `website` | `website` |
| `phone_public` | `phone` |
| `source_url` | `sourceUrl` |
| `source_name` | `sourceName` |
| `licence` | `licence` |
| `dedupe_key` | `leadDedupeKey` (idempotency; not a new lead field) |

Always send `published: false`. Slug on first insert: lead `id` (already kebab-case). Updates do not change slug.

**Do not map:** `address`, `eircode`, `email_public`, `notes_original`, `fetched_at`, `raw_refs`, lead `country` as a catalog column.

## County / NI (no second country model)

`county.country_code` is `IE` even on NI rows (`ni=true`: `antrim`, `armagh`, `derry`, `down`, `fermanagh`, `tyrone`). Import matches **county id/name**, not `lead.country == county.country_code`.

1. `GET /api/v1/counties` (32 rows).
2. Slugify `county` (same idea as `PlaceService.slugify`) and match `county.id`; else case-insensitive match `county.name`.
3. One alias: `londonderry` → `derry`. No other invented names.
4. Lead `country` (`IE` \| `NI`) is a jurisdiction hint only. Both map onto those 32 rows. No country table, no Java country enum.
5. Missing or unmatched `county` → **skip** (`countyId` is required on Place).

`place_type: other` → **skip** (not a category row; curator pick later).

## Curator gate / JSONL status

Map onto the landed enum only (`lead` \| `reviewed` \| `rejected` \| `promoted`):

| Action | Lead `status` | Catalog |
|---|---|---|
| Skip | unchanged | no Place write |
| Reject (`--reject`) | `rejected` | no Place write |
| Import | stay `reviewed` | upsert draft Place |
| Publish | `promoted` | **not this ticket** — explicit curator publish **and** [[tickets/PRD-009]] |

Default import considers only `status=reviewed`. `lead` / `rejected` / `promoted` → skip Place. Current seed lines are `status=lead` — importing `places.jsonl` as-is must create **zero** Places until a curator marks `reviewed`. That is intended.

Never set `promoted` from the importer. Never POST `published: true` from the importer.

## Steps (implementer session, after human sets `implement`)

1. Flyway V6 expand-only columns listed above. No booking columns. No country table.
2. DTO + JDBC + `PlaceService` upsert-by-`leadDedupeKey`; force unpublished when that key is set; 409 if the matched Place is published.
3. `ops/scripts/import_leads.py`: `--dry-run`, `--file`, `--base-url` (default `http://127.0.0.1:8081`), `--reject`. Stdlib only.
4. Pytest for mapping / skip / reject **without** compose (`ops/tests/test_import_leads.py`). CatalogTest (or sibling) for provenance persist, draft upsert, published-row 409, no country relation.
5. Do not add Vite/admin UI. Do not touch `product/SIGNED.md` beyond existing Wave 1 pointer.
