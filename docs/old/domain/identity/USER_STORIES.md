# Identity User Stories

## All Users (Implemented)

- As a User, I want to register using email and password so I can create an account.
- As a User, I want to sign in with email and password.
- As a User, I want to reset my password via an email link if I forget it.
- As a User, I want to verify my email address to secure my account.
- As a User, I want to update my profile details (name).
- As a User, I want to personalize my preferences after signing up (camping style, interests) so the app can tailor my experience.
- As a User, I want to upgrade my account to become an Owner or Supplier.
- As a User, I want to manage my notification preferences.
- As a User, I want to upload a profile photo during sign-up (client-side preview + post-signup upload).
- As a User, I want to log out from my profile page and be redirected to sign-in.

## Staff Stories (Implemented)

- As an Owner, I want to invite staff by email with a preset role so they can help manage my property.
- As a Supplier, I want to invite staff by email with a preset role so they can help manage my business.
- As a Staff member, I want to sign up with my invited email and automatically gain access to the portal that invited me.

## Admin Stories (Implemented)

- As a Platform Admin, I want a dedicated admin role (`isAdmin` flag) with access to the `/admin` portal.

## Developer Stories (Implemented)

- As a Developer, I want a test account dropdown on the sign-in page that auto-fills credentials for quick testing.

## Planned (Not Yet Built)

- As a User, I want to login using social accounts (Google, Apple, Facebook).
- As a User, I want to link multiple social accounts for easier login.
- As a User, I want to update my profile photo from my profile page (currently sign-up only).
- As a User, I want to delete my account and data (GDPR right to be forgotten).
