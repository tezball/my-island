# Notification User Stories

> **Status: Implemented** — In-app notifications, notification centre, pre-arrival email, and post-stay review email are all live.

## All Users (Implemented)

- As a User, I want to receive in-app notifications for important events (booking created/confirmed/cancelled, check-in/out, modifications, reviews, claims, redemptions) so I stay informed.
- As a User, I want to see a notification bell icon in the header with an unread count badge so I know when I have new notifications.
- As a User, I want to open a notification dropdown to view recent notifications with time-ago formatting.
- As a User, I want to click a notification to navigate to the relevant page (e.g., booking details, review).
- As a User, I want to mark all notifications as read with a single action.

## Guest (Implemented)

- As a Guest, I want to receive a pre-arrival email 2 days before check-in with booking details, directions, and marketplace offers.
- As a Guest, I want to receive a post-stay review request email 1 day after checkout prompting me to leave a review.

## Platform (Implemented)

- As the Platform, I want a daily scheduler (10 AM, ShedLock protected) for pre-arrival and post-stay emails so they are sent reliably without duplicates.

## Planned (Not Yet Built)

- As a User, I want to receive email notifications for new messages.
- As a User, I want to configure which notification types I receive (email, push).
- As a User, I want browser push notifications for booking alerts.
- As a User, I want optional SMS notifications for booking confirmations and arrival reminders.
