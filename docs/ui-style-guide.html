Usage Guidelines

Best practices for using the design system.

Utility Function

Use the cn() utility for merging class names:

import { cn } from '@/utils/cn'

// Merge multiple classes with conditional logic
cn('base-class', isActive && 'active-class', className)

Dark Mode Pattern

Use Tailwind's dark: prefix for dark mode styles:

// Background
className="bg-white dark:bg-surface-dark"

// Text
className="text-slate-900 dark:text-white"

// Border
className="border-gray-200 dark:border-gray-700"

Icon Usage

Import and use the Icon component with Material Symbols names:

import { Icon } from '@/components/ui'

<Icon name="camping" size="lg" />
<Icon name="star" size="md" filled />
