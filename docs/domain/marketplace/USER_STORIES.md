# Marketplace User Stories

## Supplier Stories

- As a Supplier, I want to create a profile for my business through a guided onboarding wizard.
- As a Supplier, I want to publish offers to attract guests.
- As a Supplier, I want to view claims on my offers so I can track engagement.
- As a Supplier, I want to redeem a voucher when a guest presents it (QR scanner or manual code entry), so I can mark the offer as used.
- As a Supplier, I want to see my redemption rate so I can understand offer effectiveness.
- As a Supplier, I want to subscribe to access premium features (creating offers).
- As a Supplier, I want to purchase a featured promotion so my business appears prominently in the marketplace.
- As a Supplier, I want to create test claims so I can practice the redemption flow before going live.
- As a Supplier, I want to set up Stripe Connect so I can receive payouts.

## Guest Stories

- As a Guest, I want to view local offers and experiences.
- As a Guest, I want to filter offers by category (Food, Activities, Gear, Attractions, Transport).
- As a Guest, I want to claim offers to use during my stay.
- As a Guest, I want to view my claimed vouchers and filter by status (All, Ready to Use, Redeemed).
- As a Guest, I want to display a QR code for my voucher so the supplier can easily redeem it.
- As a Guest, I want to see the claim ID as a fallback if the QR code cannot be scanned.

## Planned (Not Yet Built)

- As a Supplier, I want publishing an offer to send a push notification to apps within a 30km radius.
