# Support

## Status
Planned — Schema designed, not yet implemented.

## Overview
Will provide customer service ticket management for guests, owners, and suppliers. Support tickets can be linked to bookings for context.

## Planned Features
- Support ticket creation with categories
- Ticket status tracking (Open → In Progress → Resolved → Closed)
- Ticket messaging thread
- Booking-linked tickets for dispute resolution
