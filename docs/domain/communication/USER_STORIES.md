# Communication User Stories

> **Status: Not Yet Built** — The Communication module is planned but has no implementation. Kafka events are published for key actions but no consumer delivers notifications to users.

## All Users (Planned)

- As a User, I want to send and receive messages regarding a booking.
- As a User, I want to receive notifications for important events (booking confirmed, new review).
- As a User, I want to receive reminders for upcoming trips.
