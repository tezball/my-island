# Discovery User Stories

> **Status: Implemented** — Explore map, points of interest, travel journal, saved/favorites, and marketplace are all live.

## Guest Stories (Implemented)

- As a Guest, I want to explore an interactive map with campsite, supplier, and POI markers so I can discover things to do nearby.
- As a Guest, I want to browse points of interest by category (castles, beaches, hiking, waterfalls, etc.) to plan activities.
- As a Guest, I want to maintain a travel journal where I can track visited, wishlist, and favourite POIs with personal notes.
- As a Guest, I want to browse supplier offers in a marketplace with category filters so I can find local deals.
- As a Guest, I want to claim an offer and receive a voucher code for redemption.
- As a Guest, I want to view my claimed vouchers in a wallet with QR codes for in-person redemption.
- As a Guest, I want to save favorite lots via a heart icon so I can come back to them later.
- As a Guest, I want my saved lots to persist across sessions (API-backed for authenticated users, localStorage for anonymous).
- As a Guest, I want my anonymous saved lots to merge with my account when I log in (bulk sync endpoint).

## Planned (Not Yet Built)

- As a Guest, I want full-text search and proximity-aware search for campsites and activities.
- As a Guest, I want personalized recommendations based on my preferences and past bookings.
