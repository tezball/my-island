# Booking User Stories

## Guest Stories (Implemented)

- As a Guest, I want to search for available campsites by location so I can find somewhere to stay.
- As a Guest, I want to filter and sort search results by type, county, price, and proximity ("Near Me") so I can narrow down my options.
- As a Guest, I want to create a booking for a specific lot with date selection so I can reserve my stay.
- As a Guest, I want the system to auto-assign an available lot of my requested type so I don't need to pick a specific pitch.
- As a Guest, I want to pay securely for my reservation via Stripe.
- As a Guest, I want to receive a booking confirmation with a reference number.
- As a Guest, I want to view my upcoming, past, and cancelled trips so I can manage my travel plans.
- As a Guest, I want to cancel my booking from the Trips page if my plans change.
- As a Guest, I want to see the modification policy for my booking so I know what changes are allowed.
- As a Guest, I want to request a booking modification (date or lot change) with a price impact preview.
- As a Guest, I want auto-approved modifications applied immediately when within the owner's policy.
- As a Guest, I want modifications requiring approval to create a pending request for the owner.
- As a Guest, I want to view and cancel my pending modification requests.

## Owner Stories (Implemented)

- As an Owner, I want to view upcoming bookings, check-ins, and check-outs on my dashboard.
- As an Owner, I want to approve or reject pending bookings (confirm and capture payment).
- As an Owner, I want to see a breakdown of earnings for each booking.
- As an Owner, I want to check guests in when they arrive.
- As an Owner, I want to mark bookings as completed after the stay.
- As an Owner, I want to modify booking dates or reassign lots, with a full modification audit log.
- As an Owner, I want to view, approve, or decline guest-initiated modification requests.
- As an Owner, I want to configure my modification policy (allow/disallow, deadline days, require approval).
- As an Owner, I want to set minimum stay rules per lot (default 1 night) enforced at booking creation and modification.
- As an Owner, I want seasonal pricing rules to optionally override the minimum stay for their date range.
- As an Owner, I want to create manual bookings for walk-ins and phone enquiries.

## Planned (Not Yet Built)

- As a Guest, I want to add extras (firewood, rentals) to my booking.
- As a Guest, I want to join a waitlist when a lot type is full and be notified on cancellation.
