# PRD-017 — Guest stay search and listing detail

## Outcome

A Guest (logged out ok) searches **Stays** by county, kind (`campsite` \| `bnb`), dates, and guest count; sees map + list + price; opens a listing with photos, units, amenities, and an availability calendar. **POI Explore + VisitIntent stay as they are** — this adds stay routes, it does not rebuild the directory.

## Notes

Depends on [[ops/tickets/PRD-016]]. Same Vite PWA, Spring catalog. Leaflet + OSM (no Mapbox). Date search uses seeded open nights. Booking CTA goes to [[ops/tickets/PRD-018]] (can 401-prompt sign-in).

Keep Explore showing `poi` unless this ticket explicitly adds a Stay tab / kind filter — do not hide POIs.
