# PRD-034 — Support self-serve and role homes

## Outcome

People choose their own role and are not blocked on an engineer. Roles: **guest**, **host**, **supplier**, **curator/admin**, and **support**. Each role has a phone-first home. Support is a real role with a self-serve help path.

## Notes

Fourth product slice of [`product/FREE-DIRECTORY.md`](../../product/FREE-DIRECTORY.md). Depends on draft submit ([[ops/tickets/PRD-033]]).

**Do not set `implement` until [[ops/tickets/PRD-033]] is `done`.**

This is not the booking help center ([[ops/tickets/PRD-028]]) or the booking support inbox ([[ops/tickets/PRD-029]]). Those stay `inbox`. Help here is how a guest, host, or supplier gets unstuck inside the free directory (how to sign in, how to submit a draft, how to tick a place). Support staff use the same app. No engineer ticket is required to gain a role.

Curator publish already exists ([[ops/tickets/PRD-008]]). Do not rebuild booking admin ([[ops/tickets/PRD-026]]).

## Verify

- [ ] A person can become guest, host, supplier, curator/admin, or support without an engineer
- [ ] Each role has a home that shows that role’s job
- [ ] Support home includes a self-serve help path a stuck person can finish
- [ ] No checkout and no payment
- [ ] After merge, confirm on https://fishing-journals.com via the existing mock-prod deploy. Agents never SSH
- [ ] No GitHub Environment `production`, no `compose.prod`, no prod SSH path
