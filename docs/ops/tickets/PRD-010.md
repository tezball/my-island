# PRD-010 — Visitor auth (email, Google/Apple, session)

## Outcome

Visitors can create and keep an account (`ACC-*` in [`product/MVP.md`](../../product/MVP.md)): email+password, Google or Apple, email verify, stay signed in on a phone, password reset, display name, data export, account delete, email prefs. Spring Security + OIDC. Check-offs made before signup migrate without loss or duplication ([[ops/tickets/PRD-012]] consumes this contract).

## Notes

M1 in [`product/MILESTONES.md`](../../product/MILESTONES.md). Program: [[ops/plans/PRD-000]]. Pair UI is the PWA ([[ops/tickets/PRD-003]]); this ticket is the identity API + session. Human one-time IdP console is [[ops/tickets/WF-014]] — agents do not invent a second auth language.

Local/dev may use a stub or test IdP until the provider is picked. Do not block the plan on [[ops/tickets/WF-010]] staging.

Not booking. Not a partner portal.
