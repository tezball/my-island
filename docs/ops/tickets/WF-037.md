# WF-037 — Mock-prod info probe (version + git hash)

## Outcome

Apex Caddy proxies **health and info**. Catalog `/actuator/info` reports service, version, git SHA, branch, env, and build time. Jenkins `deploy-mock-prod` **fails** unless public info JSON matches the SHA that was just built. Health 200 on an old container is not a successful deploy.

## Notes

Silent mock-prod deploys: health stayed UP while Caddy still served the SPA (or a stale catalog image). CI must compare live `app.gitCommit` to `git rev-parse HEAD`. Not a GitHub `production` Environment.

## Verify

- [ ] Apex `GET /actuator/health` and `GET /actuator/info` reverse-proxy to catalog (not the PWA)
- [ ] Info JSON includes `app.version`, `app.gitCommit` (full SHA), `app.gitCommitShort`, `app.env`, `app.buildTime`
- [ ] `scripts/deploy-mock-prod.sh` bakes that SHA into the catalog image and fails if public info does not match
- [ ] Automated tests cover Caddy routes, info payload, and the verifier (HTML/unknown/mismatch)
- [ ] No GitHub Environment named `production`
