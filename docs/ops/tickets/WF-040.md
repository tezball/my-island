# WF-040 — Unattended mock-prod from green main

## Outcome

A green `main` (GHA `unit` + `catalog` + `web` + `stack`) starts the **commit → deploy → test → confirm** loop. Jenkins `deploy-mock-prod` deploys `origin/main` to https://fishing-journals.com/. Post-deploy: public `/actuator/info` SHA matches + **HTTP/API smoke** (not a full UI suite). Playwright is cron + MCP ([[ops/tickets/WF-011]]), not this hook. Catalog API, Chaos Monkey, ZAP already ran as **merge CI**. Gatling is a **light trickle** on the host plus **weekly** full perf — not a merge load test. Trickle/weekly failures mark Jenkins red and fire Grafana/AM ([[ops/tickets/WF-045]]). Do **not** run Chaos Monkey against fishing-journals.com on every deploy. ZAP is not a primary public-host scan. **Agents never SSH.** The SSH key stays in Jenkins. **Not** a GitHub Environment named `production`.
