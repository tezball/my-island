# WF-050 — Review-gated automerge

## Outcome

Replace [[ops/tickets/WF-025]] “CI green → github-actions auto-APPROVE + squash.” Ready same-repo non-draft PRs squash-merge **only** when GHA `unit tests` + `catalog tests` + `web tests` + `compose stack` are green **and** a GitHub pull-request review state `APPROVED` exists from an actor that is **not** `github-actions[bot]` and **not** the PR author. `CHANGES_REQUESTED` blocks. A stale approve (review `commit_id` ≠ head SHA) does not count. Chat / reviewer hats still never `gh pr merge`. Drafts and forks never auto-merge. No production Environment. Jenkins `H/5` mock-prod unchanged.

## Notes

CEO lock change 2026-09-20 (Terry). No-prod from [[ops/tickets/WF-025]] **stays**. What changes is the merge gate: Actions no longer self-approves.

Reviewer hat **may** submit Approve or Request changes. Reviewer **must not** merge or push. Implementer **must not** approve their own PR.

This ticket is docs+CI workflow only. Do not implement the consumer app.

## Verify

- [ ] `.github/workflows/ci.yml` has **no** automerge/`createReview` job (only the four tests + mock-prod-signal)
- [ ] Sibling `automerge.yml` runs on `workflow_run` (`CI` completed success) and `pull_request_review` (`submitted`)
- [ ] If CI is green and no valid Approve yet: merge job **skips/succeeds** as waiting for review — does **not** fail the PR red, does **not** merge
- [ ] Valid Approve = review state `APPROVED` (event is `APPROVE`) from non-author, not `github-actions[bot]`, review `commit_id` == head SHA
- [ ] `CHANGES_REQUESTED` blocks squash
- [ ] Drafts and forks never auto-merge; chat never `gh pr merge`
