# PRD-008 — Curator promote-from-lead in admin

## Outcome

After [[ops/tickets/PRD-001]] Place catalog skeleton, a curator can **promote a lead** from [`data/leads/places.jsonl`](../../data/leads/places.jsonl) into a Spring Place. The Place keeps the lead’s **`source_url`**, **`source_name`**, and **`licence`** from [`data/leads/schema.json`](../../data/leads/schema.json). Curator can reject or skip. **No auto-publish.** Not booking.

**Eng import / create-update (Wave 1):** a path from `data/leads` that creates or updates **draft** Places (or documents `POST /api/v1/places` from lead fields) is in scope for this ticket’s plan. Draft only — `published` false / not set. Same lead may be updated in JSONL by `dedupe_key` (Research) and later re-imported as an unpublished Place. **Still no auto-publish.** Publish remains an explicit curator step **and** [[ops/tickets/PRD-009]] counsel. Field map: [`product/WAVE-1.md`](../../product/WAVE-1.md).

## Notes

Lead record shape is [`data/leads/schema.json`](../../data/leads/schema.json) (PR #14). Do not invent a second lead DTO. Map curator actions onto the **landed** `status` enum only:

| Curator action | Lead `status` | Catalog |
|---|---|---|
| Skip | unchanged (`lead` or `reviewed`) | no Place |
| Reject | `rejected` | no Place |
| Review facts | `reviewed` | still unpublished |
| Import to draft Place | stay `reviewed` | unpublished Place; copy `source_url`, `source_name`, `licence` |
| Publish Place | `promoted` | published Place — only after explicit curator publish **and** [[ops/tickets/PRD-009]] when the batch is scraped/aggregated |

README: do not skip to `promoted` from the JSONL store alone. `promoted` means imported **and** published.

**Lead → CreatePlaceRequest-style map** (do not rename keys on the lead; do not invent a second lead DTO):

| Lead (`schema.json`) | Place / create request |
|---|---|
| `name` | `name` |
| `place_type` | `categoryId` (`poi` / `experience` / `campsite` / `bnb`; `other` needs curator pick) |
| `county` | `countyId` (32-county slug, incl. NI) |
| `lat` | `latitude` |
| `lng` | `longitude` |
| `website` | `website` |
| `phone_public` | `phone` |
| `source_url`, `source_name`, `licence` | provenance on the Place |

**Ireland geography (Architecture + Product, CEO 2026-09-05):** One Ireland geography model. Catalog seeds **32 counties as data** (NI included). Leads schema uses `country: IE|NI`. Promote maps `country: NI` (and `IE`) leads onto those county rows. Do **not** grow a second country model in Spring — no country table or country enum. Lead `country` is a jurisdiction hint for that mapping, not a catalog Country entity.

Owner: **eng-backend**. **content-seo** operates the queue. Relates to [[ops/tickets/PRD-002]] (spreadsheet bulk-import / coverage — separate). Pipeline bar: [[ops/tickets/PRD-007]]. Wave 1: [`product/WAVE-1.md`](../../product/WAVE-1.md).

**Explicitly not in this ticket:** booking, payments, inventory, partner portals, reviews, messaging, auto-publish from scrape, Next/FastAPI, a new leads schema, a Spring country table/enum.
