# PRD-015 — VisitIntent been, want, never

## Outcome

A **Guest** can browse the Ireland **Place** list, **sign in** (username/password **or** Google SSO), set one **VisitIntent** per Place (`been`, `want`, or `never`), and see those three **private** lists. **Never** is an explicit mark, not “everything else.” Signing in is required to tick; anyone can browse. Place API/UI expose an **anonymous been count** only (no PII); **want** and **never** stay private to the Guest. Same Spring catalog + Vite PWA + PostGIS. **Do not** implement [[ops/tickets/PRD-012]] / [[ops/tickets/PRD-013]] as one-tap check-off / My Places.

## Notes

CEO 2026-09-19 ([[ops/company/DECISIONS]], [`product/POI-VISITINTENT.md`](../../product/POI-VISITINTENT.md)).

**Domain:** Place, County, Guest, VisitIntent. One VisitIntent per Guest + Place; changing the mark replaces the old one. Kind stays as-is: Explore already shows `poi` only.

**Reuse:** existing Explore (county chips, search, list, map, place detail). Auth is [[ops/tickets/PRD-010]]: password **and** GIS. VisitIntent needs **any** signed-in Guest session — do not wait on password if GIS already yields `/me`. Do not replace the 101 published POIs / 32 counties.

**Authz:** VisitIntent write/read requires the Guest session. **Catalog writes lock C:** close the open `POST /api/v1/places`; no public POST/PUT/PATCH/DELETE of Places ([[ops/tickets/WF-046]]). Guests authenticate to write **VisitIntent only**. Place rows come from seed/import in CI/deploy. Do not copy `anyRequest().permitAll()`. Audit VisitIntent changes.

**Privacy:** Guest lists are **private** (session only; never another Guest’s marks). **Public counts lock A:** Place API/UI expose an **anonymous been count** only (integer, no names, ids, or other PII). **Want** and **never** stay private to the Guest — not on Place pages, not in public Place JSON.

**Out of this slice:** campsite / B&B / experience booking, one-mock-per-county listings, map rewrite, Datadog/Next/FastAPI, a second API service.

**Stream 2** (lock C): implement **now**, in **parallel** with stream 1 ([[ops/tickets/WF-040]] · [[ops/tickets/WF-041]] · [[ops/tickets/WF-042]] · [[ops/tickets/WF-043]] · [[ops/tickets/WF-044]] · [[ops/tickets/WF-045]] · [[ops/tickets/WF-046]]). Do **not** wait for deploy. Prove on local compose.
