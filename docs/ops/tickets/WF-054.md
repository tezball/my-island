# WF-054 — Automate review, CI fix, and comment fix on every PR

## Outcome

Every non-draft same-repo PR is tested by GitHub Actions, reviewed by the **my-island PR loop** automation, fixed on the PR branch when Actions or review comments are red, and squash-merged by the existing WF-050 gate once the four checks are green and a valid non-author `APPROVED` exists.
