# PRD-018 — Guest book, mock pay, confirmation

## Outcome

A signed-in **Guest** picks dates + unit + guests, sees a full EUR breakdown (nights, cleaning if any, **10% platform fee**, total), pays via the **in-catalog mock PSP** (authorize then capture), and gets a confirmation reference + Mailpit email locally. Seeded Stays are **instant-book**. Double-booking a Unit-night is impossible under concurrency.

## Notes

Depends on [[ops/tickets/PRD-017]] + Guest session [[ops/tickets/PRD-010]]. **No live card network** on mock-prod. Stripe-shaped port only — no Stripe keys in git, no second payments service.

Request-to-book is the Host-created default ([[ops/tickets/PRD-020]]); this ticket ships instant-book for seed inventory. Cancel/refund is [[ops/tickets/PRD-019]]. Policy URLs may stub until [[ops/tickets/PRD-028]].
