# PRD-003 — Light Vite+React PWA — Explore list and map

## Outcome

Phone-first **Vite + React + TypeScript PWA** shell + **Explore** (list + map, `DIR-*` / `MAP-*`): filters (category, county, facilities, been/not-been when account exists), search, distance sort, map pins/clusters, map/list toggle sharing filters, near-me with permission fallback. Talks only to the Spring catalog API.

## Notes

Client is **signed** in [`product/STACK.md`](../../product/STACK.md): light PWA, **not** Next.js App Router, **not** a Next BFF, **not** Vercel-as-default. Depends on [[ops/tickets/PRD-001]] (`GET /api/v1/places`). Program split (2026-09-06): **this ticket is Explore only**. Place detail [[ops/tickets/PRD-011]], check-off [[ops/tickets/PRD-012]], My Places [[ops/tickets/PRD-013]], auth [[ops/tickets/PRD-010]].

Not in this ticket: booking, messaging, reviews, payments, native apps, Place/Check-off/My Places screens.

Status is `ready` so a planner can write the Explore plan. **Do not write application code** until this ticket is `implement` and a plan exists.

## Verify

- [ ] Vite + React PWA (no Next.js)
- [ ] List cards: photo, name, category, county, distance when location granted
- [ ] Map + list share filters; pins by category; cluster when zoomed out
- [ ] Near-me default with non-permission fallback
- [ ] WCAG 2.2 AA on Explore (Place / My Places AA live on those tickets)
