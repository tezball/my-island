# PRD-036 — Host and Stay thin slice

## Outcome

A signed-in host adds one or more Stays. A Stay is a new place, not a claim on the 101 POIs. It stays hidden until automatic review finishes clean. Any edit hides it again. Review error or timeout keeps it hidden. There is no hand-publish. Phone and email show on the public page when present. Anonymous Place writes stay closed.

## Notes

Locked spec: [`product/HOST-STAY.md`](../../product/HOST-STAY.md). This does not mark [[ops/tickets/PRD-034]] done. [[ops/tickets/PRD-033]] stays `plan` for supplier drafts and curator publish. Do not promote [[ops/tickets/PRD-016]]–[[ops/tickets/PRD-029]].

Kinds: campsite, bed and breakfast, apartment, glamping, lodge. No hotels. One page per Stay. Admin is the server-checked Google account. Unban does not publish.

- [x] Public Place POST stays import-only. PUT/PATCH/DELETE of Places stay denied. Host writes are authenticated `/api/v1/host/stays`
