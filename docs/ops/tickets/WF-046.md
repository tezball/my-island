# WF-046 — Close public Place writes; seed/import only

## Outcome

**No public POST / PUT / PATCH / DELETE of Places.** Place rows change only via **seed/import in CI or deploy** (Flyway, import scripts, job-started compose). Guests authenticate to write **VisitIntent only** ([[ops/tickets/PRD-015]]). **Close** the current open `POST /api/v1/places` (`anyRequest().permitAll()` in catalog SecurityConfig). Anonymous GETs of the directory stay public.

## Notes

Catalog writes lock **C** (CEO 2026-09-19). Today `POST /api/v1/places` is reachable without a session. That hole must close on local compose, Testcontainers, and fishing-journals.com.

Place mutations are **not** a Guest API. They are not a curator HTTP API on the public host in this slice. Seed/import stays the Wave 1 path ([[ops/tickets/PRD-008]] landed) — CI/deploy scripts talking to Postgres or a loopback-only job, not an anonymous HTTP write Caddy exposes.

Guest session writes: VisitIntent upsert/delete under `/api/v1/me/…` only. Auth is [[ops/tickets/PRD-010]]. Do **not** invent a public Place admin.

Contract tests must **deny** unauthenticated Place writes (401/403) and must **not** keep proving a public create as the happy path. List/get remain public. Workshop sim / STACK-E2E history that POSTed places is archaeology — do not re-open the public verb.

Same parallel land as stream 1 ([[ops/tickets/WF-044]]) and stream 2 ([[ops/tickets/PRD-015]]). ZAP ([[ops/tickets/WF-044]]) should see Place writes fail without a privileged path.

## Verify

- [x] `POST` / `PUT` / `PATCH` / `DELETE` `/api/v1/places` (and `/api/v1/places/{id}`) return 401/403 without a privileged CI/deploy path
- [x] No `permitAll()` on Place writes; directory GET/list stay anonymous 200
- [x] Place rows in compose/mock-prod come from seed/import (Flyway / CI/deploy scripts), not public HTTP
- [x] Guest session can write VisitIntent only — not Places ([[ops/tickets/PRD-015]])
- [x] Gherkin/Testcontainers contract asserts the deny; create-list-get no longer depends on public POST
- [x] No secrets in notes; `python3 -m pytest ops/tests -q -m "not stack"`
