# PRD-021 — Host calendar, availability, pricing

## Outcome

A Host sets **availability** (open / blocked nights, min stay) and **pricing** (base nightly EUR, optional seasonal rule) per Unit. Guest search ([[ops/tickets/PRD-017]]) and checkout ([[ops/tickets/PRD-018]]) use the same tables. Effective-price preview shows which rule applied.

## Notes

Depends on [[ops/tickets/PRD-020]]. Seed calendars from [[ops/tickets/PRD-016]] remain valid until a Host edits them. Out: iCal sync, dynamic-pricing suggestions, OTA channel sync ([`product/EXPANSION.md`](../../product/EXPANSION.md) “deliberately not planned”).
