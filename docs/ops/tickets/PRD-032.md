# PRD-032 — Listing kinds on the map

## Outcome

A guest on a phone can see **campsite**, **B&B**, **experience**, and **supplier** listings on the existing Explore list and map, next to the published POIs. `supplier` is a new listing kind (farm shop or other small business). Kinds stay data, not a closed code enum. Free. No checkout.
