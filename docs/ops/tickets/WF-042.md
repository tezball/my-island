# WF-042 — Agent MCP pack for mock-prod

## Outcome

Agents see and act on mock-prod **only through MCP plus public HTTPS**. Pack: catalog API/health, Jenkins job status + deploy-on-main, Gatling trigger/status, Playwright, Postgres read-only, deploy/status (info SHA). Grafana/PromQL is [[ops/tickets/WF-041]]. **No secrets in `docs/`.** Cloud agents **do not SSH**.

## Notes

CEO 2026-09-19. Laptop `.cursor/mcp.json` is local stdio (Grafana, Postgres, GitHub, Docker, Playwright, IntelliJ). Cloud runs do not load that file. This ticket documents and attaches the **mock-prod** pack (HTTP/SSE or dashboard catalog) so an agent can check the site, read status, trigger Gatling, and troubleshoot without a shell on the VPS.

If a tool needs a shell on the box, it is a Jenkins job or MCP wrapper — not an agent SSH session. Credentials live in Jenkins / agent environment secrets.

Gatling lock (CEO 2026-09-19): a **light trickle** against https://fishing-journals.com/ is ongoing smoke through all features — **not** a merge-CI load test. **Full Gatling performance** is **weekly Jenkins cron** and/or MCP/manual. Do **not** put full perf on every merge. Login as a **seeded password Guest** ([[ops/tickets/PRD-010]]) — not Google.

**Alerts lock C:** trickle smoke and weekly Gatling failures mark **Jenkins red** and fire **Grafana/Alertmanager**. Agents read both via MCP. Leftover FJ email stays muted ([[ops/tickets/INC-001]]). Fail-path ticket: [[ops/tickets/WF-045]].

Chaos is merge CI ([[ops/tickets/WF-043]]); ZAP is merge CI ([[ops/tickets/WF-044]]). Playwright is cron + MCP ([[ops/tickets/WF-011]]). Do **not** run Chaos Monkey against public fishing-journals.com on every deploy. Traffic must not wipe disks or drop the git checkout.
