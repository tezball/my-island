# PRD-020 — Host identity and listing onboard

## Outcome

A person with the **Host** role (same Spring account model as Guest; role grant) can create a **draft Stay** (campsite or B&B): photos, description, units, location in an Irish county. Drafts are **not public**. Admin publish is [[ops/tickets/PRD-026]] (Host may not self-publish in this ticket). Seed Hosts own the mock seed Stays.

## Notes

Depends on [[ops/tickets/PRD-016]] + [[ops/tickets/PRD-010]]. This is **not** public Place POST ([[ops/tickets/WF-046]]). Writes go to `/api/v1/host/…` with a Host session. Skip Chunk 1 “claim existing Place” — Hosts create new Stays.

Default for Host-created Stays: **request-to-book** until they enable instant ([[ops/tickets/PRD-021]] / [[ops/tickets/PRD-022]]).
