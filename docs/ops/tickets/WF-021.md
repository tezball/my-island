# WF-021 — Simple local CLI for start/stop/test

## Outcome

Terry has one local command for the Halfdoor stack: `./scripts/app start`, `./scripts/app stop`, `./scripts/app test`. Start reuses `./scripts/dev up` (PostGIS, Grafana, Loki, Prometheus, Alertmanager, catalog API), opens the human URLs when a display exists, and prints a ready summary. Test brings the stack up if needed, runs the same checks humans care about, and prints a one-screen PASS/FAIL report.

## Notes

Merged [#35](https://github.com/tezball/my-island/pull/35) 2026-09-06. CEO ask. Thin wrapper — do not rewrite compose. Chaos stays **off** on default start (no `compose.chaos.yml`, no Spring profile `chaos`). No consumer UI (that's [[ops/tickets/PRD-003]]). Catalog smoke uses stub fields `categoryId` / `countyId` / `latitude` / `longitude` ([[ops/tickets/WF-018]]). Keeps [[ops/tickets/WF-019]] `./scripts/sim-place-listing.sh`.
