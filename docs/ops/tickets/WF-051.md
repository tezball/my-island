# WF-051 — Jenkins posts PR checks; isolate compose; Maven/npm cache

## Outcome

Laptop Jenkins `my-island` multibranch posts GitHub commit statuses named **`unit tests`**, **`catalog tests`**, **`web tests`**, and **`compose stack`** on the built SHA. The stack stage uses a separate Compose project and host ports so it does not recreate the engineer’s `my-island` stack. Maven `~/.m2` and npm caches persist on named volumes. GHA test jobs stay (dual-run). Do **not** change branch protection or make the repo private in this PR.

## Notes

Follow-up (not this PR): retarget required checks to Jenkins contexts, update `gate_mock_prod_deploy.py` to accept commit statuses, keep a thin GHA automerge, delete GHA test jobs, then private.

Classic PAT in `.env` as `JENKINS_GITHUB_TOKEN` (`repo` scope). Chat never prints the token. No production Environment.
