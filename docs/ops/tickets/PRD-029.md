# PRD-029 — Support inbox and tickets

## Outcome

Guest or Host opens a **SupportTicket** (topic, Booking id optional, body). Admin/support inbox lists open/pending/closed; replies in-thread; can link a Dispute ([[ops/tickets/PRD-027]]). Mailpit locally. This is **not** Guest–Host messaging.

## Notes

Depends on [[ops/tickets/PRD-026]] + [[ops/tickets/PRD-028]]. Same Spring API + admin routes. No Zendesk. No SSH to read mail.

## Verify

- [ ] Signed-in user creates a ticket; anonymous 401
- [ ] Support inbox 403 for plain Guest/Host
- [ ] Reply visible to the requester; status changes audited
- [ ] Optional Booking link
- [ ] No third-party helpdesk; no Next.js BFF
