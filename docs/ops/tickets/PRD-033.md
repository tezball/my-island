# PRD-033 — Free host and supplier draft submit

## Outcome

A signed-in **host** can submit a campsite or B&B, and a signed-in **supplier** can submit a shop, as an authenticated **draft**. A curator publishes it. Guests never pay. Anonymous `POST /api/v1/places` stays closed.

## Notes

Third product slice of [`product/FREE-DIRECTORY.md`](../../product/FREE-DIRECTORY.md). Depends on kinds being on the map ([[ops/tickets/PRD-032]]).

**Do not set `implement` until [[ops/tickets/PRD-032]] is `done`.** Full role homes and the support help path are [[ops/tickets/PRD-034]]. This ticket only needs a signed-in host or supplier role so the form is not anonymous.

Do not promote [[ops/tickets/PRD-020]] (booking onboard) or [[ops/tickets/PRD-018]] (mock pay). Hosts do not claim existing POIs (decision 34). Experiences and POIs can stay curator-seeded.

## Verify

- [ ] Authenticated host draft for `campsite` or `bnb`; authenticated supplier draft for `supplier`
- [ ] Drafts are not public until a curator publishes
- [ ] Anonymous Place POST/PUT/PATCH/DELETE stays closed ([[ops/tickets/WF-046]])
- [ ] No checkout, payment gateway, calendar, or booking
- [ ] After merge, confirm on https://fishing-journals.com via the existing mock-prod deploy. Agents never SSH
- [ ] No GitHub Environment `production`, no `compose.prod`, no prod SSH path
