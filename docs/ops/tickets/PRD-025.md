# PRD-025 — Host payouts ledger (mock)

## Outcome

Each captured Booking credits a **Host ledger** (gross − 10% platform fee − refunds). Host sees balance + statement. A weekly **mock payout batch** zeros the available balance (no bank API, no real money). Failed-payout rows can be marked by admin.

## Notes

Depends on [[ops/tickets/PRD-018]]. Refunds from [[ops/tickets/PRD-019]] debit the ledger. No Stripe Connect, no IBAN in git. Mock-prod only.

## Verify

- [ ] Ledger math matches captured Bookings minus refunds and fee
- [ ] Host cannot see another Host’s statement
- [ ] Mock payout batch is idempotent
- [ ] No live bank/Stripe Connect keys
- [ ] No Next.js BFF
