# WF-024 — PostGIS image has no ARM64 (app start fails on Apple Silicon)

## Observed

`./scripts/app start` (and `./app start` from `scripts/`) dies on Apple Silicon:

```
✘ Image postgis/postgis:17-3.5-alpine Error no matching manifest for linux/arm64/v8
Error response from daemon: no matching manifest for linux/arm64/v8 in the manifest list entries
```

Official Hub `postgis/postgis:17-3.5` / `…-alpine` publish **linux/amd64 only**.

## Expected

`./scripts/app start` pulls and starts PostGIS 17 + PostGIS 3.5 on Apple Silicon (linux/arm64) and on amd64 (CI, Cloud Agents) without qemu pinning.

## Notes

CEO laptop repro 2026-09-12. Compose + Testcontainers both pinned the Hub alpine tag. House stack stays PostgreSQL 17 + PostGIS (`product/STACK.md`). Image vendor is not locked.

Drop-in: `ghcr.io/baosystems/postgis:17-3.5` (linux/amd64 + linux/arm64). Recreate volumes if this machine already ran the Hub alpine image (`docker compose down -v`).
