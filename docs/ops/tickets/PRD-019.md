# PRD-019 — Guest trips, cancel, refund

## Outcome

A Guest sees **Trips** (upcoming / past / cancelled), opens a Booking, cancels with the **refund amount shown before confirm**, and gets mock-PSP refund status. Check-in notes release 48h before arrival (seed copy ok).

## Notes

Depends on [[ops/tickets/PRD-018]]. Cancellation policy is one of flexible / moderate / strict (planner lock in [`product/BOOKING-SITE.md`](../../product/BOOKING-SITE.md)). Admin override is [[ops/tickets/PRD-027]].

Private to the Guest. No PII on public Place pages.
