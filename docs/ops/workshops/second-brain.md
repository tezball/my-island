# Second brain workshop

CEO / Terry: the vault should feel like **Jira + Confluence + engineer notes** as one shareable site — colour, Maps of Content per group, templates, Dataview.

## Goal

A website-like atlas on top of the existing OS. Do **not** move tickets or product paths. Colour folders in the explorer. Humans browse [[ATLAS]]; agents still use [[ops/BOARD]].

## Success bar

- [[ATLAS]] + group MOCs
- `notes/` for engineer thinking
- Templates: moc / wiki / note / adr / meeting
- Folder + note colour in `company-os.css`
- Dataview on indexes
- Ticket SoT unchanged
