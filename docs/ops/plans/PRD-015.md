# Plan: VisitIntent been, want, never

## Outcome

On the **existing** Spring catalog + Vite Explore PWA, a **signed-in Guest** (username/password **or** Google SSO) sets one **VisitIntent** per **Place**: `been`, `want`, or `never`. The three lists are **private**. Place API/UI expose an **anonymous been count** only (no PII). **Want** and **never** stay private to the Guest. Browse stays public. Ireland seed unchanged. Done when ticks and the three lists work on local compose. Mock-prod follows `main` via stream 1 — **do not wait** on deploy.

## Out of scope

- Implementing [[ops/tickets/PRD-012]] / [[ops/tickets/PRD-013]] as written
- Campsite / B&B / experience booking; per-county mocks; map rewrite
- Removing GIS; inventing a second IdP
- Next.js, FastAPI, Neon, Datadog, a second API service
- Public or cross-Guest VisitIntent lists
- Named people on Place pages (counts are anonymous integers only)
- Public want/never Place aggregates (**Public counts lock A:** been count only)
- Replacing the live catalog dump

Auth **implementation** (password + seed Guests) is [[ops/tickets/PRD-010]]. This ticket consumes the session.

## Domain

| Term | Meaning |
|---|---|
| **Place** | A point of interest people can visit |
| **County** | Irish county the Place sits in |
| **Guest** | A person using the site to browse and tick places |
| **VisitIntent** | The Guest’s mark on a Place: `been`, `want`, or `never` |
| **Rule** | One VisitIntent per Guest + Place. Changing the mark replaces the old one |
| **Kind** | Place kinds already exist (`poi`, `campsite`, `bnb`, `experience`). Explore shows `poi` only — leave that |

Host / Experience owner / Support: glossary only; no UI in this slice.

## Steps

1. Flyway expand-only: `visit_intent` with unique `(guest_id, place_id)`, mark enum, timestamps. Audit of changes.
2. Spring: session-authenticated GET/PUT (upsert) / DELETE under `/api/v1/me/…`. Any signed-in Guest (GIS **or** password). Reject anonymous writes. Lists are **private**.
3. PWA: keep Explore. Add tick control + three **private** lists. Place API/UI expose **anonymous been count** only (no PII). Want and never stay off Place pages. Optimistic UI; one Guest per browser.
4. Contract: Gherkin + Testcontainers (authz, upsert replace, unique, private lists, public been count has no PII, no public want/never counts). Vitest. Playwright via cron + MCP ([[ops/tickets/WF-011]]), not merge.
5. **Close** `POST /api/v1/places` (lock C, [[ops/tickets/WF-046]]). Guests write VisitIntent only. Place seed/import stays CI/deploy. Do not add booking columns.
