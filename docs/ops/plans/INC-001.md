# Plan: Mute leftover fishing-journals down-alert email

## Outcome

Mock-prod (fishing-journals.com VPS) stops emailing “API is down” / site-down alerts. Leftover fishing-journals Alertmanager has a no-op `keep` receiver. Prometheus no longer evaluates `ApiDown` against the retired `api:8081` scrape. `deploy-mock-prod.sh` keeps that mute in place. Pre-release: we are not on-call for this host.

## Out of scope

- GitHub Environment `production`
- New my-island core-path alerts ([[ops/tickets/PRD-014]], [[ops/tickets/WF-009]])
- Moving Grafana off `grafana.fishing-journals.com`
- Silencing via Grafana MCP (SAFETY: `--disable-write`)

## Steps

1. On the VPS: rewrite leftover Alertmanager to `keep` (no email) **before** dropping rules, so a resolved notification cannot send.
2. Empty leftover Prometheus `alerts.yml` (`groups: []`). Restart Prometheus so the bind-mount is picked up.
3. Land `ops/deploy/disable_legacy_alerts.py` and call it from `scripts/deploy-mock-prod.sh`.
4. Document on [[ops/runbooks/MOCK_PROD_DEPLOY]].
