# Plan: Gatling trickle and weekly perf fail Jenkins plus Grafana

## Outcome

When the **light trickle** or the **weekly full Gatling** job fails, Jenkins shows **red** and house Grafana/Alertmanager **fires**. Cloud Agents read Jenkins (WF-042 pack) and alerts (Grafana MCP HTTP/SSE, `--disable-write`). Leftover fishing-journals Alertmanager email stays **muted** ([[ops/tickets/INC-001]]).

## Out of scope

- Restoring leftover FJ SMTP / `ApiDown` email
- Full Gatling on every merge ([[ops/tickets/WF-042]])
- Alertmanager webhook spawning an agent ([[ops/tickets/WF-009]])

## Steps

1. Jenkins jobs for trickle smoke and weekly perf fail the build on non-zero Gatling/smoke (red ball, not a silent log).
2. House Prometheus/Grafana Alerting: rules that fire when those jobs fail or when trickle error-rate/latency crosses a documented bar. Receiver is house Alertmanager — **not** leftover FJ email (`keep` stays on the VPS leftover stack).
3. Document agent read path: Jenkins MCP/HTTP for job color; Grafana MCP for firing alerts (same observe lock C datasources [[ops/tickets/WF-041]]).
4. Confirm `deploy-mock-prod.sh` still runs `disable_legacy_alerts.py`. Do not add `email_configs` to leftover AM.
