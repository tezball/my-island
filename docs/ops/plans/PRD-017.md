# Plan: Guest stay search and listing detail

## Outcome

PWA Stay search (county, kind, dates, guests) + map/list + listing detail using PRD-016 inventory. POI Explore and VisitIntent untouched. Done when a logged-out Guest can find a Kerry campsite for next weekend on local compose.

## Out of scope

- Checkout pay ([[ops/tickets/PRD-018]])
- Host calendar UI ([[ops/tickets/PRD-021]])
- Showing `campsite`/`bnb` inside the POI-only Explore list (add a Stay surface instead)

## Steps

1. Catalog: `GET /api/v1/stays?county=&kind=&checkIn=&checkOut=&guests=` filters Units with all nights `open` and `capacity >= guests`. Return min price.
2. `GET /api/v1/stays/{id}` with units, nights summary, photos, amenities.
3. PWA routes `/stays` and `/stays/:id` (Leaflet OSM). CTA “Check availability” / “Book” disabled or sign-in until PRD-018 — still show price.
4. Vitest filters; Testcontainers search contract; Playwright via [[ops/tickets/WF-011]] later.
