# Plan: Unattended mock-prod from green main

## Outcome

Merging to `main` is enough. Jenkins `deploy-mock-prod` deploys `origin/main` to https://fishing-journals.com/, then **post-deploy test confirms** (info SHA + smoke; Gatling/MCP via [[ops/tickets/WF-042]]). Agents never SSH. The SSH key stays in Jenkins. There is no GitHub Environment `production`. Loop: **commit → deploy → test → confirm**.

## Out of scope

- GitHub Environment `production`, `compose.prod`, prod SSH
- Agents copying or using the mock-prod SSH key
- Deploying a feature / worktree branch
- House Grafana sidecars on the VPS overlay ([[ops/tickets/WF-041]])
- Product VisitIntent ([[ops/tickets/PRD-015]])

## Steps

1. Trigger `deploy-mock-prod` when `main` GHA `unit` + `catalog` + `web` + `stack` are green (Jenkins GitHub status, scan of `main` after automerge, or a thin GHA→Jenkins ping). Jenkins already runs `scripts/deploy-mock-prod.sh`.
2. Confirm the key is only in Jenkins / gitignored host env. Fail closed if `MOCK_PROD_*` is missing — same as today’s groovy.
3. Keep the public info SHA gate. Health UP on a stale container is not success.
4. Document: agents watch Jenkins job status + public HTTPS. They do not SSH. Kill the **human** deploy gate in [[ops/workflow/PIPELINE]] and the runbook “from a machine with MOCK_PROD_*” as the *agent* path.
5. Post-deploy confirm: public health + info SHA + **HTTP/API smoke** — not Playwright. Gatling **light trickle** may already be running on the host ([[ops/tickets/WF-042]]); full perf is weekly, not this hook. Chaos Monkey is merge CI ([[ops/tickets/WF-043]]) — **not** on the public host every deploy. ZAP is merge CI against local compose ([[ops/tickets/WF-044]]). Trickle/weekly fail → Jenkins red + Grafana ([[ops/tickets/WF-045]]).
