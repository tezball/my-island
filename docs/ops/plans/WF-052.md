# Plan: Dedicated Jenkins CI checkout directory

## Outcome

Jenkins `prepare` can `mkdir` a host-visible copy of `$WORKSPACE` under one dedicated directory. Done when the helper path, the compose mount, and the vault tests agree, and the runbook says the running container must be recreated later. Do not recreate Jenkins in the PR that lands this.

## Out of scope

- Recreating or restarting the Jenkins container (a publish-main turn is using the laptop)
- Bind-mounting all of `~/Projects`
- Editing PR 117 or the primary clone `~/Projects/my-island`
- GitHub Actions, branch protection, or product code

## Steps

1. **Path.** `jenkins_ci_host_root` writes `$JENKINS_CI_ROOT/<job>`, default `$(dirname "$HOST_REPO")/my-island-ci/<job>`. Stop writing siblings named `my-island-ci-<job>` directly under `~/Projects`.
2. **Mount.** Jenkins service bind-mounts only that parent directory, at the same host path, so Docker Desktop file sharing can see the copy. Leave the primary-clone mount as it is.
3. **Refuse early.** If that parent is missing or not writable, `jenkins_ci_prepare` exits 1 and says to recreate the container. Do not fall back to `~/Projects`.
4. **Docs + test.** Runbook and CI note name the directory and the recreate. Pytest freezes the path and the volume line.

## Verify

- [ ] Default root is `…/my-island-ci/<job>`, not `…/my-island-ci-<job>`
- [ ] `JENKINS_CI_ROOT` override replaces the parent
- [ ] Compose volume is that directory, not `~/Projects`
- [ ] Unwritable parent fails prepare before `mkdir` of the job directory
- [ ] `python3 -m pytest ops/tests -q -m "not stack"`

Implement bar (company draft): [[ops/workflow/DOD]] — outcome, automated proof for the risk, CI-runnable, no nits-as-blockers.

## MCP / env

No stack start. No Grafana. The Jenkins recreate is a later operator step on the machine that runs compose.
