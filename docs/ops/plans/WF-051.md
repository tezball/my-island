# Plan: Jenkins posts PR checks; isolate compose; Maven/npm cache

## Outcome

Multibranch Jenkins posts the same four GitHub status names GHA uses, without taking down the laptop compose stack, and without re-downloading Maven/npm every build. Done when a PR job can show those four contexts on GitHub and vault tests pin the wiring. GHA tests stay until a follow-up.

## Out of scope

- Deleting `.github/workflows/ci.yml` test jobs
- Changing GitHub branch protection / making the repo private (human)
- Teaching `gate_mock_prod_deploy.py` to read commit statuses (needed only after GHA tests go)
- Chaos / ZAP / Gatling / Playwright
- Product UI

## Steps

1. **Host-visible checkout.** `$WORKSPACE` lives on the `ops_jenkins` volume. Copy it to `$(dirname "$HOST_REPO")/my-island-ci-<job>` so `docker compose` bind-mounts resolve on Docker Desktop. Do not build the dirty primary tree.
2. **Four statuses.** `ops/scripts/jenkins_github_status.py` POSTs `unit tests` / `catalog tests` / `web tests` / `compose stack` (`pending` at stage start, `success`/`failure` in `post`). Token = `JENKINS_GITHUB_TOKEN`. Skip (exit 0) if the token is missing/`changeme`.
3. **Isolate stack.** `COMPOSE_PROJECT_NAME=my-island-ci`, `SKIP_JENKINS=1`, `SKIP_WEB=1`, host ports via `OPS_*_HOST_PORT` (15433, 18081, …). Seed uses `CATALOG_URL=http://host.docker.internal:$OPS_CATALOG_HOST_PORT`.
4. **Caches.** Compose volumes `ops_m2` + `ops_npm` on `workspace`. Web `docker run` mounts `my-island_ops_npm`.
5. **Docs + tests.** CI / JENKINS_LOCAL note the four Jenkins contexts. Vault/unit tests freeze names, isolate env, volumes. Do not remove GHA jobs.
