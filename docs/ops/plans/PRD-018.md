# Plan: Guest book, mock pay, confirmation

## Outcome

Signed-in Guest completes instant-book on a seeded Stay: hold nights → mock authorize → capture → Booking confirmed + reference. EUR breakdown includes 10% platform fee. Concurrent requests cannot double-book a Unit-night.

## Out of scope

- Live Stripe/Adyen; Host payouts ([[ops/tickets/PRD-025]])
- Guest cancel UI ([[ops/tickets/PRD-019]])
- Request-to-book confirm/decline ([[ops/tickets/PRD-022]])
- Real SCA / 3DS

## Steps

1. Flyway: `booking` (guest, unit, dates, status, totals, mock_payment_id) + night holds tied to `unit_night`.
2. Mock PSP in catalog: authorize/capture/fail/refund methods. No network keys. Fail path via test header or `fail=true` in compose only.
3. `POST /api/v1/me/bookings` requires Guest session. Seed Stays `instant_book=true` → capture immediately.
4. Mailpit email locally; mock-prod log/no-op.
5. Testcontainers: happy path, 401, mock fail with no row, two parallel posts → one 409/conflict.

## Verify

- [ ] Breakdown before pay
- [ ] Double-book impossible
- [ ] Phantom-booking impossible on PSP fail
- [ ] Confirmation on API + PWA
- [ ] No payment secrets in notes

Implement bar: [[ops/workflow/DOD]].
