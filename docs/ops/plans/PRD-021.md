# Plan: Host calendar, availability, pricing

## Outcome

Host edits `unit_night` and pricing rules. Guest search/checkout read the same data. Seasonal rule preview names the rule. No iCal/OTA/dynamic pricing.

## Out of scope

- iCal import/export, channel managers, weekend/LOS complexity (Chunk 8)
- Guest-facing search (already PRD-017)

## Steps

1. Flyway: `price_rule` (stay/unit, date range, nightly EUR, name).
2. Host APIs to block/open nights and upsert rules. Effective price = rule else base.
3. PWA `/host/calendar`. Cross-host 403.
4. Contract: blocked night disappears from search; min stay rejects short range at quote time.
