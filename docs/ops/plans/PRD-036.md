# Plan: Host and Stay thin slice

## Outcome

A signed-in host adds a Stay. It stays hidden until automatic review finishes clean. There is no hand-publish. The public page shows phone and email. Host id, username, feedback, and ban reason stay off the public JSON. Anonymous Place writes stay closed. Nobody pays.

## Out of scope

- Dates, payment, messages, hotels, checkout ([[ops/tickets/PRD-016]]–[[ops/tickets/PRD-029]] stay `inbox`)
- Supplier drafts and curator publish ([[ops/tickets/PRD-033]] stays `plan`)
- Role homes and the support help path ([[ops/tickets/PRD-034]] stays `plan`)
- Claiming one of the 101 POIs
- GitHub Environment `production`, `compose.prod`, prod SSH

## Steps

1. Authenticated host API at `/api/v1/host/stays`. Not the public Place POST.
2. Kinds: campsite, bed and breakfast, apartment, glamping, lodge. One page per Stay. Ireland pin. County comes from the pin.
3. Automatic review, fail-closed: tech, then fit, then conduct. A website, if present, must be a normal http(s) URL and must load. A redirect is a down site. Review does not follow it.
4. Admin is the configured Google account, checked on the server. Actions: run review again, unban. Unban does not publish.
5. After merge, mock-prod deploy from `main` and confirm on https://fishing-journals.com. Agents never SSH.
