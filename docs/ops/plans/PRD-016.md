# Plan: Stay inventory schema and mock seed

## Outcome

Spring catalog gains **Stay** / **Unit** (Flyway expand-only) on Place kinds `campsite` and `bnb`. CI/deploy seeds ≥1 mock campsite and ≥1 mock B&B per 32 Irish counties, with photos, EUR nightly price, and 12 months of open nights. 101 POIs unchanged. Done when list/get Stay APIs work on local compose against that seed.

## Out of scope

- Guest search UI ([[ops/tickets/PRD-017]]), checkout, Host UI
- Public Place POST ([[ops/tickets/WF-046]] stays closed)
- Replacing POI seed; scraping Booking.com / operator galleries
- Next.js, FastAPI, a second API service, live payments

## Domain

| Term | Meaning |
|---|---|
| **Stay** | Bookable Place of kind `campsite` or `bnb` |
| **Unit** | Room or pitch on a Stay |
| **Host** | Account that will own Stays ([[ops/tickets/PRD-020]]); seed uses a seeded Host |
| **County** | Existing 32-county list (ROI+NI) |

## Steps

1. Flyway: `stay` (place_id unique, host_id nullable until PRD-020, cancellation_policy enum, instant_book bool default true for seed) + `unit` (stay_id, capacity, base_price_eur) + `unit_night` (unit_id, date, state open\|blocked). Unique `(unit_id, date)`.
2. Read APIs under `/api/v1/stays` (public GET). No public POST.
3. Seed job in CI/deploy (same lane as Place import). Attribution on photos (Wikimedia or clearly licensed placeholders). Admin/seed flag `mock=true`.
4. Gherkin/Testcontainers: per-county coverage query; POI count regression; GET stay; unit nights exist.
