# Plan: Mock-prod apex cutover (remove fishing-journals)

## Outcome

my-island is the public site at `https://fishing-journals.com/`. The fishing-journals test stack is dumped and stopped. Google Sign-In reuses the existing Web client: GIS popup + `POST /api/auth/google` `{ "idToken" }`. Done when public health is catalog JSON and Explore loads at `/`.

## Out of scope

- GitHub Environment `production`
- Password auth ([[ops/tickets/PRD-010]])
- Apple Sign-In ([[ops/tickets/WF-033]])
- Moving Grafana off `grafana.fishing-journals.com`

## House picks

| Item | Pick |
|---|---|
| Host | Existing AWS VPS (fishing-journals.com), mock-prod not prod |
| Edge | Existing Caddy on `server_default`; patch to island-web / island-catalog |
| Auth | GIS ID token, path `/api/auth/google` (fishing-journals contract) |
| Data | my-island PostGIS; FJ postgres dumped then stopped |

## Steps

1. Spring GIS: verify Google ID token, session cookie, `GET /api/v1/me`.
2. PWA Google button + apex static nginx image.
3. Caddy: apex + `app.` → my-island; `/explore` → `/`; admin/venues redirect.
4. Deploy script: rsync, compose up, dump+stop FJ apps, health-check apex.
5. Jenkins job calls the script.

## Verify

- [x] Catalog contract: stub Google login → session → `/api/v1/me` → logout
- [x] Caddy patcher unit test (apex routes, GIS `/api/auth*`, Grafana kept)
- [x] Public `https://fishing-journals.com/actuator/health` JSON UP
- [x] Explore at `/`; fishing-journals website gone
- [x] No secrets in `docs/ops/`
