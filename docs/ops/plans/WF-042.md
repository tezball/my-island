# Plan: Agent MCP pack for mock-prod

## Outcome

A Cloud Agent can, via MCP plus public HTTPS: check catalog/PWA health, read Jenkins job status, trigger deploy-on-main (Jenkins, not SSH), trigger/status Gatling, drive Playwright against the public URL, and `SELECT` catalog (read-only). Grafana is [[ops/tickets/WF-041]]. No secrets in `docs/`.

## Out of scope

- SSH from agents
- Write Postgres MCP
- Grafana `--disable-write` exceptions
- IntelliJ MCP on Cloud Agents
- Secrets, host IPs, or key paths in tickets/plans
- Playwright as merge CI ([[ops/tickets/WF-011]] is cron + MCP only)
- Moving Chaos / ZAP to cron
- Full Gatling performance on every merge

## Steps

1. Name the pack in [[ops/workflow/MCP]] (and STACK inventory row): catalog HTTP/API, Jenkins, Gatling, Playwright, Postgres RO, deploy/status. Grafana pointer to WF-041.
2. Attach for Cloud Agents via dashboard HTTP/SSE or catalog MCP. Do not rely on laptop `.cursor/mcp.json` stdio following the VM.
3. Jenkins: status of `local-ci` / `my-island` / `deploy-mock-prod` + trigger deploy-on-main only. Key stays in Jenkins ([[ops/tickets/WF-040]]). **Lock C:** that trigger runs on the Mac mini self-hosted worker (loopback Jenkins) — [[ops/tickets/WF-049]]. Do not expose Jenkins to Cloud VMs over HTTPS (not B). Do not GHA SSH (not D).
4. Gatling: **light trickle** on https://fishing-journals.com/ as ongoing smoke through features (not a merge-CI load test). **Full performance** = weekly Jenkins cron and/or MCP/manual. Seeded password Guest ([[ops/tickets/PRD-010]]). Do not put full perf on automerge `needs`. Chaos Monkey merge CI is [[ops/tickets/WF-043]]; ZAP is [[ops/tickets/WF-044]]. Must not wipe disks or drop git.
5. Fail path is [[ops/tickets/WF-045]]: trickle/weekly failure marks **Jenkins red** and fires house Grafana/Alertmanager. Agents read both via MCP. Leftover FJ email stays muted.
6. Playwright MCP against https://fishing-journals.com/ (and local compose). Playwright **CI** is cron-only [[ops/tickets/WF-011]] — not automerge.
7. Postgres RO: existing `ops_reader` / `postgres-catalog`. No new credentials in git.
