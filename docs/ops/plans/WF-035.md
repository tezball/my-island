# Plan: Test stack — shift-left mix for human and agent

## Outcome

Company-state map of **what we test today vs what we want**, written for CTO + QA + agents. Tests double as **tools and entrypoints** (sim already; Gatling traffic, API BDD, Playwright MCP next). Done when [[ops/workflow/TEST_STACK]] and [[ops/workshops/cto-test-stack]] are on `main` and vault tests freeze them.

## Out of scope

- Adding Gatling, Cucumber, Vitest, or Playwright **code** in this PR (follow-up tickets after the map lands)
- Dual Playwright + Cucumber **UI** (legacy tax — [`product/ENGINEERING.md`](../../product/ENGINEERING.md) §3.4)
- Chaos in required CI
- Inventing a marketplace test suite
- Mutation testing / PITest as a merge gate

## Value

The factory is the agent loop. A thin CI pyramid plus **reusable runners** (sim, traffic, scenarios) lets an agent seed local data, watch Grafana, and prove a slice without a human ritual. The failure mode is either a single-layer “unit only” stack or a tax of two UI E2E frameworks.

## Steps

1. Write [[ops/workflow/TEST_STACK]] — layers, today vs want, CI vs tool vs workshop, shift-left rules.
2. Workshop + canvas for the CTO 5-minute walkthrough.
3. Point DOD, CI, PIPELINE, QA dashboard, eng-qa, SKILLS / AGENT_DX, HOME at the map.
4. Vault freeze in `ops/tests/test_vault.py`. `board_sync.py`.
5. **Later sessions (do not file in this PR):** Gherkin skin on the existing `catalog` Testcontainers job; Gatling `./scripts/dev traffic` (same operate lane as sim); Vitest with [[ops/tickets/PRD-003]]; Playwright job [[ops/tickets/WF-011]].
