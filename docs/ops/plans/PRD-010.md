# Plan: Visitor auth — email + password (MVP)

## Outcome

Visitors can **sign up and log in with email + password** on the Spring catalog (`services/catalog`). Session cookie works for the phone PWA. Pre-signup check-off migrate contract for [[ops/tickets/PRD-012]] is documented. **No OIDC stub.** Google Sign-In is a **follow-up** when Terry provides `client_id` / `client_secret` ([[ops/tickets/WF-014]]); do not fake Google in MVP.

**Done when** signup/login/logout/`/me` work under Testcontainers + local compose, Mailpit handles verify/reset locally, anonymous Place GETs still work, and secrets never land in `docs/ops/`.

## Out of scope (MVP)

- OIDC stub endpoints (`/api/v1/auth/stub/oidc`, stub IdP containers)
- Live Google/Apple until credentials exist (seam only — see Follow-up)
- Vite login screens (PWA pairs later; JSON + cookie contract here)
- Visit migrate implementation ([[ops/tickets/PRD-012]])
- Locking down `POST /api/v1/places` (workshop + seed importers)

## House picks

| Item | Pick |
|---|---|
| Runtime | Same Boot app: `services/catalog` |
| Security | `spring-boot-starter-security` |
| Session | Spring Session JDBC + HttpOnly cookie (30 days) |
| Passwords | BCrypt; min 10 chars |
| Mail | Mailpit on local compose |

## HTTP (MVP)

| Method | Path | Auth |
|---|---|---|
| POST | `/api/v1/auth/signup` | anon |
| POST | `/api/v1/auth/login` | anon |
| POST | `/api/v1/auth/logout` | session |
| GET | `/api/v1/me` | session |
| PATCH | `/api/v1/me` | session |
| POST | `/api/v1/auth/verify/resend` | session |
| GET | `/api/v1/auth/verify` | anon `?token=` |
| POST | `/api/v1/auth/password/forgot` | anon |
| POST | `/api/v1/auth/password/reset` | anon |
| GET | `/api/v1/me/export` | session |
| DELETE | `/api/v1/me` | session |

Schema: `app_user`, `user_identity` (issuer=`password` only for MVP), `email_token`, Spring Session tables. No visit FK.

Migrate contract for PRD-012: after login, client POSTs `/api/v1/me/visits/migrate` (404 until PRD-012). Document in ticket/plan; do not fake visit inserts.
