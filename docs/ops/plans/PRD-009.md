# Plan: Counsel gate before publish

## Outcome

**Leads ≠ publish.** Research may deposit scraped or aggregated facts into [`data/leads/`](../../../data/leads/README.md) as unpublished leads. **No agent may bulk-publish Places from that store** (or from any scraped/aggregated copy) until a **human counsel sign-off** is recorded in git as a **name + date**.

This plan **is** the policy note. Done when the verify list is checkable, [[ops/tickets/PRD-009]] is not `implement` until a human says so, and no application code has landed. Parent program: [[ops/plans/PRD-000]] (Wave 1; PR [#55](https://github.com/tezball/my-island/pull/55)).

## Out of scope

- Application code (Java/Spring, Flyway, Vite/React PWA, import scripts)
- Scrapers, CAPTCHA/auth bypass, copying aggregator prose/photos into publish fields
- A second lead schema or DTO — canon is [`data/leads/schema.json`](../../../data/leads/schema.json) (PR [#14](https://github.com/tezball/my-island/pull/14) / [[ops/tickets/PRD-006]])
- Rewriting [`product/SIGNED.md`](../../product/SIGNED.md) or [`product/STACK.md`](../../product/STACK.md) (not a stack change)
- Checking [`product/BRIEFING.md`](../../product/BRIEFING.md) §6 seed-content as fully answered
- Booking, Stripe, Next.js, FastAPI, brand lock (public name stays **OPEN**)
- Waiving this gate because Wave 1 is accepted ([`product/WAVE-1.md`](../../product/WAVE-1.md) does **not** waive counsel)
- Filling the sign-off table below with an agent name

## Policy (product + trust-safety)

CEO 2026-09-05 approved aggressive multi-source collection for **leads only** ([`data/leads/LEGAL.md`](../../data/leads/LEGAL.md), [[ops/company/DECISIONS]] #6). The signed directory is **curator-seeded**, not a dump of Research inventory ([`product/SIGNED.md`](../../product/SIGNED.md)).

[`product/BRIEFING.md`](../../product/BRIEFING.md) §6 seed-content (licensed / scraped / open data / in-house) is **partially** answered: scrape into leads is allowed; **publish is still open** and sits with counsel.

| May (no counsel) | Must not (until human name+date in git) |
|---|---|
| Deposit/update JSONL leads ([[ops/tickets/PRD-007]], `status=lead`) | Bulk-publish Places from leads or aggregator copy |
| Curator `reviewed` / `rejected` | Set lead `status=promoted` in bulk from scrape |
| Eng import **draft** Places, `published` false ([[ops/tickets/PRD-008]]) | POST/PATCH `published: true` on lead-backed rows |
| Curator-authored original or licensed descriptions | Copy scraped prose, reviews, or photos into publish fields |
| Facts allowed by the lead’s `licence` for *internal research* | Treat `licence` as a grant to republish third-party copy |

`licence` on [`schema.json`](../../../data/leads/schema.json) is “how we may use captured facts” (e.g. `internal-research`). It is **not** a republish licence. EU database-right / ToS risk on aggregator lists is unchanged ([`LEGAL.md`](../../data/leads/LEGAL.md)).

**Pipeline (stop points):**

```
scrape / collect → data/leads JSONL (PRD-007)
  → curator review
  → draft Place, published=false (PRD-008)
  → counsel name+date in git (this ticket)
  → curator explicit publish
```

Agents stop at PRD-007 and PRD-008. [[ops/tickets/PRD-002]] seed work may plan against this note; it still must not publish scraped copy.

## Sign-off (human only)

Record **before** any bulk publish from scraped/aggregated content. One of: ticket comment on [[ops/tickets/PRD-009]], a run note, or a short line in this plan. **No secrets.**

| Field | Value |
|---|---|
| Counsel name | _empty — human fills_ |
| Date (ISO) | _empty — human fills_ |
| Scope | Bulk publish from scraped/aggregated leads |
| Recorded by | Terry (human) + counsel — never an agent |

Format: `Counsel: <full name>, <YYYY-MM-DD>`. Empty table means **not signed**. Agents must not invent a name or date.
