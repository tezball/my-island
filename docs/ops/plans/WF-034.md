# Plan: Agent DX pack — skills, commands, plugins, MCP

## Outcome

Goal 1: a reviewable list (workshop) of skills, slash commands, plugins, and MCP servers for clone-and-run DX on this stack. Goal 2 (later): land the **selected** rows in git so the next engineer does not assemble a toolbox by hand.

Done for Goal 1 when the workshop is on `main` and IntelliJ is a house MCP on that list. Done for Goal 2 when selected configs are committed and clone/test still works with IntelliJ closed.

## Out of scope

- Installing marketplace plugins as a human ritual (clone must not depend on Customize)
- Cloud Agent MCP attach from `environment.json` (still a dashboard human step — [[ops/tickets/WF-016]])
- Committing `.idea/` (gitignored)
- Product UI skills that petrify scaffolding beyond a thin Spring / Vite pointer
- Enabling IntelliJ “brave mode” (run configs without confirmation)
- Vite PWA skill, Mailpit MCP, marketplace plugin wrap (LATER)

## Value (planner)

**8.5 / 10.** This company’s asset is the agent loop, not a consumer app. Clone → `./scripts/app start` → skills/MCP is the factory. A curated pack compounds on every later ticket. The failure mode is **inventory bloat** (always-on rules, unused MCP, marketplace junk). Goal 1 list → Goal 2 selected install is the right split.

IntelliJ MCP is a **house MUST** (Java/Spring engineers live there). It does not raise the score to 10: Cloud Agents will not have IDEA running.
