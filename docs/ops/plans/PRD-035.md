# Plan: Phone-first look and feel refactor

## Outcome

The live PWA is visually refit for a phone: photo-led cards, readable type, one-thumb Explore / detail / journey lists. Stack stays Vite + React + TypeScript talking to Spring. Done when those screens match the directory, not a booking site.

One palette from [`product/LOOK.md`](../../product/LOOK.md), matching the Stitch export: page `#f4fbf6`, cards `#ffffff`, text `#161d1a`, primary `#002217`, field note `#0f382a`, amber accent `#904d00` / `#fe932c`. Directions uses the primary, not amber. Brown `#c98400` is not used.
