# Plan: Free host and supplier draft submit

## Outcome

A signed-in host saves a campsite or B&B draft. A signed-in supplier saves a supplier draft. A curator publishes. The public map shows only published rows. Anonymous Place writes stay closed. Nobody pays.

## Out of scope

- Payment gateway, basket, mock PSP, availability calendar, instant book ([[ops/tickets/PRD-018]] and the rest of PRD-016–029 stay `inbox`)
- Claiming an existing POI
- The full support help center ([[ops/tickets/PRD-034]])
- Opening `POST /api/v1/places` to anonymous clients
- GitHub Environment `production`, `compose.prod`, prod SSH

## Steps

1. Authenticated draft API under a host/supplier path (the booking note’s `/api/v1/host/…` shape is fine). Not the public Place POST. Supplier drafts use the same catalog and the `supplier` kind.
2. Minimum role on the existing account (password or Google, already on `main`) so the caller is a host or a supplier. Seed accounts stay in env, never in `docs/`.
3. Drafts are unpublished. Curator publish uses the existing curator path ([[ops/tickets/PRD-008]]). Guests see the place only after publish.
4. Phone-first submit form: name, county, map point, contact or how to visit. Free. No price, no dates.
5. After merge, mock-prod deploy from `main` and confirm on https://fishing-journals.com: a draft is absent from `published=true`, a published row appears, anonymous Place POST stays 401. Agents never SSH.
