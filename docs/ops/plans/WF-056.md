# Plan: Hundred-user Gatling pulse

## Outcome

An operator can start Jenkins `gatling-pulse` and get a 10-minute, 100-user walk of today's customer APIs against https://fishing-journals.com, plus the standard Gatling HTML report on the build. The scheduled trickle stays a short 10-user check. Flyway has already seeded those accounts.

## Out of scope

- Editing `scripts/deploy-mock-prod.sh` or making the pulse downstream of deploy
- A second cron, or pointing `H/15` at 100 users or a 10-minute hold
- Clicking Build, SSH, or running the pulse against the public site from this session
- Choosing an A/B cutover
- Merge-CI load
- Signup, verify, forgot, reset, Google, or a second place corpus

## Steps

1. Flyway `V11__gatling_pulse_seed.sql`: 100 idempotent users (`pulse-001`..`pulse-100`, test password `guest`, house BCrypt). Cohorts from new (no visits) through heavy. Visits attach to existing `place` rows only.
2. One named chain per shipped customer API in `GuestFeatureChains`. Trickle injects 10 of those users for one walk (100% bar). Pulse holds 100 users for 10 minutes with think time (99% / p95 go/no-go). Local pulse default stays `http://127.0.0.1:8081`.
3. JCasC job `gatling-pulse`: no cron, no upstream. Sets `https://fishing-journals.com`. Archives `gatling-report/**`. Red notifies house Alertmanager and does not roll a deploy back.
4. House note [[ops/workflow/GATLING]] plus the DoD feature line: a new customer API adds a chain.

## Verify

- [ ] Job file has no `cron(` and no upstream; deploy job does not call it
- [ ] Pulse simulation `during(Duration.ofMinutes(10))` and trickle does not
- [ ] Seed hash matches `BCryptPasswordEncoder` for `guest`
- [ ] Vault pytest `not stack`
- [ ] Gatling sources compile
- [ ] Pulse was not executed against https://fishing-journals.com

Implement bar (company draft): [[ops/workflow/DOD]] — outcome, automated proof for the risk, CI-runnable, no nits-as-blockers.

## MCP / env

No prod Grafana write. No SSH. Jenkins job is seeded by JCasC when Jenkins reloads; this session does not click Build.
