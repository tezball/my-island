# Plan: Seed catalog DB from research leads

## Outcome

Local compose boots a **non-empty Place catalog** by loading [`data/leads/places.jsonl`](../../data/leads/places.jsonl) (Wave 1 research, ~114 leads) into Postgres `catalog`. Explore and e2e can list real campsite/place rows without a spreadsheet path.

**Done when** `./scripts/app start` (or `./scripts/dev up`) leaves Places queryable via `GET /api/v1/places?published=true`, rows carry provenance (`sourceUrl` / `sourceName` / `licence` / `leadDedupeKey`), and re-seed is idempotent on `lead_dedupe_key`. No second lead schema. No booking columns.

## Out of scope

- Spreadsheet / CSV curator import (dropped for MVP; reopen later if needed)
- Counsel waiver for public launch ([[ops/tickets/PRD-009]] still `gate: human` before claiming counsel-approved publish)
- Scrapers, personal data dumps beyond the landed JSONL
- Consumer PWA ([[ops/tickets/PRD-003]]); auth ([[ops/tickets/PRD-010]])
- Photos / object storage
- Replacing [[ops/tickets/PRD-008]] `import_leads.py` semantics — **reuse or wrap** it; do not invent a parallel importer

## Approach

1. **Source of truth:** `data/leads/places.jsonl` + [`schema.json`](../../data/leads/schema.json) (PR #14). Map `place_type` → `categoryId` (`campsite` / `poi` / …), county names → `countyId` (same aliases as PRD-008).
2. **Load path (pick smallest that works):**
   - Prefer: on catalog boot / `./scripts/dev up`, run existing `ops/scripts/import_leads.py` (or a thin `seed_from_leads.sh`) against `http://127.0.0.1:8081` after health, **or**
   - Flyway `db/seed` (dev profile only) generated from JSONL — only if HTTP import is flaky in CI.
3. **Publish for local MVP:** seed rows as **`published: true`** so Explore is usable. Document clearly: this is **local/dev demo seed**, not counsel sign-off. Any shared/staging/public fleet still needs [[ops/tickets/PRD-009]] before treating scraped batches as launch content.
4. **Idempotent:** upsert on `lead_dedupe_key`; skip/collide safely on re-run.
5. **Facts only:** name, location fields, website/phone when public on the lead; do **not** copy aggregator review prose into `description` beyond short `notes_original` if already treated as curator-safe facts in Wave 1.

## Steps (implementer)

1. Wire seed into `./scripts/dev up` / catalog ready path; document in [[ops/runbooks/JENKINS_LOCAL]] or [[ops/workflow/LOCAL]].
2. Prove: empty DB → up → `GET /api/v1/places?published=true` returns many rows; second up does not duplicate.
3. Pytest without compose where possible (mapping); `@pytest.mark.stack` or catalog Testcontainers for load if needed.
4. Do not add CSV tooling. Do not set counsel complete.
