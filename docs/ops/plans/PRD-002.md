# Plan: Curator seed — create, spreadsheet import, name+proximity dedup, coverage

## Outcome

Curators can **create** a Place and **bulk-import** a spreadsheet into the PRD-001 catalog so the directory is not empty. Every imported row records **source + licence**. Imports (and curator creates that are not the workshop stub) are **deduplicated by normalised name + proximity**. A **coverage** report shows counts by the 32 counties × listing-type categories (draft vs published). All writes from this ticket stay **unpublished**. Done when an implementer PR has the thin Spring + script path and the verify steps below pass.

Lead shape stays [`data/leads/schema.json`](../../data/leads/schema.json) (PR #14). Do **not** invent a second lead schema, a Java Lead DTO, or a parallel JSONL. Promote-from-lead / draft import is already [[ops/tickets/PRD-008]] (`ops/scripts/import_leads.py`, Flyway V6 provenance + `lead_dedupe_key`). This ticket does **not** redo that importer. Counsel / publish is [[ops/tickets/PRD-009]]. Program: [[ops/tickets/PRD-000]] · [`docs/ops/plans/PRD-000.md`](PRD-000.md) (Wave 1 callsign **mvp-seed**).

## Pick: CSV script + small Spring match/coverage

Same house as PRD-008: Python stdlib CLI talks HTTP to Spring; catalog JSON stays camelCase. Spreadsheet headers are **Place / `CreatePlaceRequest` fields**, not lead snake_case.

**Implementer shape (smallest that fits):**

1. **Python CLI** `ops/scripts/import_spreadsheet.py` (stdlib `csv` + urllib, like `import_leads.py`). Reads UTF-8 CSV, maps headers → `CreatePlaceRequest`, `POST`s `/api/v1/places` with `published: false`. `--dry-run` prints payloads and collision notes, does not POST. `--base-url` default `http://127.0.0.1:8081`. `--file` required.
2. **Name + proximity on write** when `leadDedupeKey` is **absent**: if another Place has the same normalised name **and** `ST_DWithin(location, new_point, 250 metres)`, **409** and do not insert. Do not overwrite published or unpublished rows via this path (leads upsert stays PRD-008 only).
3. **Match endpoint** for dry-run (do **not** hang it under `GET /api/v1/places/{idOrSlug}` — that would steal the path). Use a sibling: `GET /api/v1/place-matches?name=&latitude=&longitude=&radiusMeters=250`.
4. **Coverage endpoint** `GET /api/v1/coverage`: every county row × every category row (data, not a Java enum), with `draft`, `published`, `total`. Zeros included so thin cells are visible. Optional CLI `ops/scripts/coverage_report.py` curls that JSON and prints a table.
5. **No new lead columns.** No Flyway unless a functional index on normalised name is genuinely needed — the geography GIST already exists. Expand/contract only; no booking columns; no country table.

Do **not** parse CSV inside Spring. Mapping lives in the script.

## Spreadsheet → Place (not a second schema)

Header row = camelCase catalog keys. Unknown headers → fail the file (do not silently drop). Extra lead keys (`place_type`, `dedupe_key`, `fetched_at`, …) are **invalid** here — those rows belong in `data/leads/places.jsonl` + `import_leads.py`.

| CSV header | `CreatePlaceRequest` | Required? |
|---|---|---|
| `name` | `name` | **yes** |
| `categoryId` | `categoryId` — `poi` / `experience` / `campsite` / `bnb` only ([[data/listing-types]]) | **yes** |
| `countyId` | `countyId` — 32-county id, or county name resolved like `import_leads.py` (`londonderry` → `derry`) | **yes** |
| `sourceUrl` | `sourceUrl` | **yes** |
| `sourceName` | `sourceName` | **yes** |
| `licence` | `licence` | **yes** |
| `description` | `description` | original curator prose only; omit rather than paste aggregators |
| `town` | `town` | |
| `latitude` / `longitude` | `latitude` / `longitude` | omit if unknown; **do not invent** |
| `website` / `phone` | `website` / `phone` | public business only |
| `facilityIds` | `facilityIds` | semicolon-separated ids from `V3__facility.sql` (`parking`, `toilets`, `dog_friendly`, `accessible`) |
| `slug` | `slug` | optional; else slugify `name` |
| `priceBand` | `priceBand` | `FREE` \| `1` \| `2` \| `3` |

Always send `published: false`. If the sheet has a `published` column, **ignore it** (or fail the row if `true`) — this importer is not a publish path. Do not set `leadDedupeKey` from the spreadsheet.

**Skip row** (leave catalog unchanged, report in the run summary): missing required field; unknown `categoryId`; unmatched county; `place_type`-shaped sheet; coordinates out of range. **Collision** (name + proximity, or name + same county when either point is missing): skip unless `--force` (still unpublished). Never 200-overwrite a published Place.

Commit a tiny synthetic fixture `ops/fixtures/curator-seed.example.csv` (2–3 fake rows, no personal emails/phones). Do **not** commit Research dumps or scraped PII.

## Dedup rules (CUR-05)

Distinct from lead `dedupe_key` / `lead_dedupe_key` (PRD-008 idempotency).

1. **Normalised name:** same idea as `PlaceService.slugify` (lower, non-alnum → hyphen, trim). Equality on that string — not fuzzy Levenshtein in this ticket.
2. **Proximity:** `ST_DWithin` on `place.location`, radius **250 m** (constant `PLACE_DEDUP_RADIUS_METERS`). Both points required.
3. **Weaker fallback:** if either row has no coordinates, same normalised name **and** same `countyId` is a collision for the spreadsheet (skip / dry-run note). Workshop POST may keep today’s slug-unique 409 only when the new point is null — document the choice in the implement PR; prefer the weaker match so two “Killarney House” drafts in Kerry do not land.
4. **Lead upsert unchanged:** `leadDedupeKey` present → existing PRD-008 path (update unpublished; 409 if published). Do not add proximity onto that path this ticket.

## Coverage (CUR-13)

Query `county` ⨯ `category` (LEFT JOIN `place`). Do **not** hardcode the four type ids in Java — read the tables so [[ops/runbooks/LISTING_ROLLOUT]] stays “types are data”. NI counties are ordinary rows (`ni=true`). Response sketch:

```json
{
  "radiusMetersUsed": null,
  "cells": [
    {"countyId": "kerry", "categoryId": "campsite", "draft": 3, "published": 0, "total": 3}
  ]
}
```

Include every pair (32 × N categories), even when `total` is 0. `draft` = `published = false`. Thin = `published == 0`.
