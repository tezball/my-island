## E2e journey (the bar)

One visitor path. Automate as soon as the PWA exists ([[ops/tickets/WF-011]]). Until then, prove each arrow with HTTP + unit tests.

```
open PWA on phone (or desktop width)
  → Explore: map/list of published places, near-me or Ireland fallback
  → filter category + county; search name
  → tap place → Place detail (photos, facts, directions, nearby)
  → one-tap ✓ (no modal) before account — stored locally
  → signup (email or Google/Apple) → local ticks migrate, no dupes
  → My Places: list, map, total, 32-county count
  → airplane mode → tick → reconnect → one visit row
  → curator: reviewed lead → draft Place → counsel → publish
  → MCP: PromQL `up{job="catalog"}` + core-path alert visible
```

Success metrics in MVP §7 must be **instrumented before launch**, not after. Thresholds written down before launch day.
