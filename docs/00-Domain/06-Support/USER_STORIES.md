# Support User Stories

> **Status: Not Yet Built** — The Support module is planned but has no implementation in the backend or frontend.

## User Stories (Planned)

- As a User, I want to create a support ticket when I have an issue.
- As a User, I want to track the status of my support requests.

## Staff Stories (Planned)

- As a Staff member, I want to view open tickets.
- As a Staff member, I want to respond to tickets and resolve issues.
