# Identity User Stories

## All Users

- As a User, I want to register and login using email or social accounts.
- As a User, I want to update my profile details (name, photo, bio).
- As a User, I want to manage my notification preferences (email, push, sms).
- As a User, I want to link multiple social accounts for easier login.
- As a User, I want to delete my account and data.
