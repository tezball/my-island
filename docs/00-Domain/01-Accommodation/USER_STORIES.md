# Accommodation User Stories

## Owner Stories

- As an Owner, I want to create and update campsite details so that guests can see accurate information.
- As an Owner, I want to manage lot inventory and pricing so that I can maximize revenue.
- As an Owner, I want to set availability calendars to prevent double bookings.
- As an Owner, I want to configure check-in instructions so guests know how to arrive.
- As an Owner, I want to add facilities and amenities to show what my campsite offers.
- As an Owner, I want to upload photos of my campsite and lots to attract guests.
- As an Owner, I want to create a campsite in the least amount of steps to save time.

## Guest Stories

- As a Guest, I want to view campsite details, facilities, and rules before booking.
- As a Guest, I want to see detailed information about specific lots (size, capacity, amenities).
