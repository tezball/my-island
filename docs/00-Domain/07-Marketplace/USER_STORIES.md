# Marketplace User Stories

## Supplier Stories

- As a Supplier, I want to create a profile for my business.
- As a Supplier, I want to publish offers to attract guests.
	- This will send a push notification to the apps local to the business, say 30 km radius
- As a Supplier, I want to view claims on my offers so I can track engagement.
- As a Supplier, I want to redeem a voucher when a guest presents it, so I can mark the offer as used.
- As a Supplier, I want to see my redemption rate so I can understand offer effectiveness.

## Guest Stories

- As a Guest, I want to view local offers and experiences.
- As a Guest, I want to claim offers to use during my stay.
- As a Guest, I want to view my claimed vouchers so I can use them later.
- As a Guest, I want to display a QR code for my voucher so the supplier can easily redeem it.
- As a Guest, I want to see the claim ID as a fallback if the QR code cannot be scanned.
