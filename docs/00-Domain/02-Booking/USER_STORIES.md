# Booking User Stories

## Guest Stories

- As a Guest, I want to search for available campsites by date and location.
- As a Guest, I want to create a booking for a specific lot.
- As a Guest, I want to add extras (firewood, rentals) to my booking.
- As a Guest, I want to pay securely for my reservation.
- As a Guest, I want to receive a confirmation of my booking.
- As a Guest, I want to cancel my booking if my plans change (subject to policy).

## Owner Stories

- As an Owner, I want to view upcoming bookings.
- As an Owner, I want to check guests in when they arrive.
- As an Owner, I want to mark bookings as completed after the stay.
- As an Owner, I want to see a breakdown of earnings for each booking.
