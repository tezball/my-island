# Seed review

A seeded stay is public only if it would pass the review bar: plain text, a PNG or JPEG, and a pin on the island (latitude 51.0 to 55.5, longitude -11.0 to -5.0). A website, if one were set, would also have to load. The seed has no photos and no websites, so those stays are hidden.

Kerry glamping 001 is the exception. Its text is plain, its pin is already on the island, and the migration attaches a small PNG. That stay is public and its listing page shows the image.

Tools: Flyway `V4__harden.sql`, PostgreSQL.
